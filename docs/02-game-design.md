# Game Design Document

状态：`Working Draft`

这是玩法设计的唯一主文件。新想法先记录，不直接默认为正式规则。

## 核心循环

当前正式切片已经实现以下外层，但状态仍为 `Proposed`：

```text
开始新局 / 继续 → 选择牌组 → 进入东圈
→ 选当前关：闲局或庄局打一副或跳过换手气；圈主必须打
→ 单副达标 → 金币入账 → 百宝阁 → 下一关
→ 东 / 南两圈共六关 → 短局通关 → 可选西圈加赛
```

标准局最多打 2 圈 × 3 关 × 1 副；最后一关通关后直接结束，所以全打进入 5 家百宝阁。
跳过闲局或庄局会缩短局长，也会放弃该关分数、过关金币和商店，换取一次性或下一关生效的手气。
每个圈主只改一个可预告变量；牌组把牌背与一条开局修正绑定。完整提案见
`docs/decisions/0017-short-run-shop-cadence.md`，实现不代表已经接受。

需要验证：标准局能否落在 5–8 分钟、六关内构筑能否成形、五家商店是否都有购买价值，以及玩家是否愿意主动进入西圈。

以下是已经归档为历史对照的旧核心循环。最初的 Demo：

```text
选择盲注 → 抽牌 → 选择至多五张 → 出牌/弃牌
→ 牌型与福神牌计分 → 达标结算 → 商店构筑 → 下一盲注
```

V1 提案（根据首轮试玩反馈需要修订）：

```text
14 张未整理牌 → 单张换牌，或锁定 2–4 张有效组合
→ 未整理牌与已锁定组合共同构成结构手牌
→ 拼成完整胡牌 → 结算筹码、胡法与福神牌
→ 达标结算 → 商店构筑 → 下一盲注
```

V2 提案（已做成历史垂直切片，仍待用户试玩判断）：

```text
14 张结构牌 → 单张换牌，或亮出 2–4 张组合赚取收益
→ 任意时刻只要完整结构合法，即可主动胡牌
→ 亮组消耗行动，触发本副灵签；完全不亮则保留门清金币奖励
→ 行动耗尽：可胡则结算，不可胡则流局
```

V2 把四件事分开：

1. **胡牌资格**：由完整 14 张结构判断，首批同时支持普通胡与七对。
2. **整副基础分**：最终合法分解里的对子、顺子、刻子和杠都会自动计分，不要求逐组亮出。
3. **亮组收益**：玩家主动亮组触发本副临时灵签与额外得分，但放弃门清金币奖励。
4. **胡法倍率与福将**：屁胡、七对、碰碰胡等提供倍率；商店福将整局持续改变规则。

V2 当前为 `Proposed`，不是已冻结规则。三副牌、待结算奖励、三选一商店和第二轮福将验证已实现于 `prototype/v2-run-shop-demo/`；自动测试只能证明流程成立，仍需用户试玩判断“门清金币”和“亮牌灵签”是否真的形成选择。详见 `docs/decisions/0007-hu-eligibility-and-reveal-scoring.md`、`docs/decisions/0008-concealed-gold-vs-reveal-fortune.md` 与对应试玩记录。

### V2 垂直切片参数

- 每副 5 次行动，最多主动亮 2 组；胡牌已经就绪时仍可继续亮牌。
- 0 / 1 / 2 次亮牌后胡，分别产生 3 / 1 / 0 枚待结算金币。
- 每次亮牌取得一张可预览的本副灵签；灵签在下一副消失。
- 三副全部胡牌并达到目标才让本轮金币入账；失败会清空整轮待结算奖励。
- 第一轮目标 1100，商店三件福将价格为 2 / 5 / 8；第二轮目标 1900。
- 支持普通胡、七对、碰碰胡、清一色、一条龙、大三元和大四喜；番种倍率采用加法累积。
- 第一轮用于亲手比较门清与开运，第二轮用于立即看到购买的福将生效。

以上数字均属于试玩实验值；用户试玩前不提升为 `Accepted`。

### 下一轮提案：六个开运位与三签选一

状态：`Proposed`

用户反馈认为 V2 的基础方向正确，但固定两次亮牌、固定下一签和 3 / 1 / 0 金币曲线不够有构筑感。下一轮改测：

```text
每副显示 6 个开运位
→ 亮一个合法组合，花掉 1 格
→ 当场出现 3 张本副灵签，选择 1 张立即生效
→ 不亮的空格在胡牌后按格兑换待结算金币
→ 短期灵签提高本副分数，长期金币购买后续福将
```

六格是可消费的奖励机会，不是胡牌必须填满的结构槽。普通胡最多实际亮 5 个结构组，七对最多亮 6 对并保留一对未亮。单张换牌不占开运位；换牌预算与开运位应分开记录。

首轮纸面参数建议每个空位 2 金，因此 0–6 次亮牌对应 12 / 10 / 8 / 6 / 4 / 2 / 0 基础金币。每次三选一至少包含一张能强化刚亮组合的稳定选项，另外两张提供牌型上限、随机高收益或 +1 / +2 待结算金币。所有灵签只在本副生效，未使用开运位和财签金币仍要等检查点过关后入账。

该方案把每次亮牌的机会成本固定为 2 金，但会带来六次选择拖慢节奏、普通胡与七对经济不对称、商店价格整体膨胀等风险。完整规则、替代方案和接受条件见 `docs/decisions/0009-six-fortune-slots-and-three-choice-draft.md`。

### 历史 V3 街机切片（已实现，`Proposed`）

上面的提案已经做成可试玩切片 `prototype/v3-arcade-demo/`，视觉延续 `legacy-demo.html` 的街机牌馆方向。实现过程中修订了四处参数，理由和模拟数据见 `docs/decisions/0010-arcade-slice-and-empty-slot-value.md`：

```text
14 张结构牌（发牌器保证有解，界面写明目标牌型）
→ 点 1 张换牌（每副 5 次，牌桌上常驻显示牌墙前两张）
→ 点 2–4 张亮出合法组合，花 1 个开运位，原位三签选一
→ 结构合法即可随时胡牌
→ 得分 = 牌值 × 番势
   牌值 = 50 + 各组底分 + 空开运位 × 12 + 灵签 / 福将
   番势 = 1 + 番种加值 + 灵签 / 福将
→ 金币 = 空开运位 × 2 + 财签
→ 三副累计达标才让金币入账 → 百宝阁买福将 → 下一轮
```

与 V2 的关键差别：

- **取舍是平滑的**：每花一个开运位固定失去 12 牌值和 2 金，换一次三签选一。门清只是番种名，不再提供番势，避免「第一次亮牌就损失一半分数」的断崖。
- **失败只吃掉本副**：流局本副 0 分，之前几副的分数和待结算金币保留；只有整轮不达标才清空待结算。
- **换牌与开运位彻底分开**：换牌 5 次，开运位 6 个，互不消耗。
- **随机可复现**：网址加 `?seed=数字` 复盘同一局。

V3 的历史实验参数是三轮、每轮三副，目标 900 / 1700 / 4500。这些数字不再描述当前 `src/`。

V3 留下的已知问题仍然有效：旧三轮结构太短，长期金币路线的复利来不及体现，自动模拟里「全亮冲分」始终分数更高。`0013` 曾用更多关卡拉长兑现窗口，但用户认为九关两副明显过慢，因此被 `0017` 的高频商店短局替代。

### 当前短局方向（`Proposed`）

`0017` 将外层收缩为：

- 标准局只有东、南两圈；每圈依次经过闲局、庄局和圈主，每关一副。
- 初始测试目标为东圈 `400 / 550 / 700`、南圈 `800 / 1350 / 2200`。
- 闲局和庄局可跳，跳过后得到财气、签气、免单气或顺气之一；圈主不可跳。
- 圈主从五条单变量规则中按 seed 选取；一局内不重复。
- 开始界面可选素面、玉髓、朱漆、墨玉四种牌组，牌背与开局修正绑定。
- 每个打赢的非最终关后进入百宝阁；标准局全打五家，跳过的关没有商店。
- 南圈圈主后算短局通关；玩家可选择进入西圈三关加赛。
- 存档 schema v4 记录圈、关、手气、圈主、牌组、手内状态、完整签局和待缘位，并从 v1 / v2 / v3 逐级迁移。

这些都是实验参数，不是 `Accepted`。主要风险是六关内长期构筑来不及兑现、五家商店的收入与价格失配，以及单副失败的惩罚变重。

## 玩家每次决策

1. 这次换哪张牌，还是亮出一个组合开运？
2. 哪些牌值得保留来追求目标胡法？
3. 是花掉一个开运位做三签选一、追分或改命，还是把空位留成长期金币？
4. 商店的钱花在哪里？
5. 灵签、番谱、福将、牌骨和牌印如何形成一条可读的构筑方向？

## 系统清单

当前正式 `src/` 已实现（其中玩法规则仍为 `Proposed`）：

- 14 张结构牌与保底可解牌墙
- 换牌、2–4 张亮组、六个开运位
- 番种识别、`牌值 × 番势`
- 本副灵签、番谱、四槽福将、牌骨与牌印
- 东 / 南两圈标准局、闲局 / 庄局 / 圈主、每关一副、西圈可选加赛与关卡失败重试
- 跳局手气、四种起始牌组、牌帖、标准局五家三货位百宝阁
- 开始 / 继续 / 设置界面、固定 seed 与 schema v4 存档
- 「百牌谱」五系图鉴；抽签、商店、计分与图鉴共用同一功能卡 Library

仍待验证或决定：

- 六关目标、过关金、商品价格和刷新成本是否匹配
- 完整非跳局路线与常见跳局路线的目标时长
- 牌骨 / 牌印最终采用牌种改造还是持久实体牌库
- 圈主池、牌组修正和手气强度是否公平

卡包、利息、无尽模式和局外数值成长仍只是候选，不代表第一版全部保留。圈主、跳局手气、牌组和西圈加赛已进入 `0017` 的 `Proposed` 切片，但也不因此成为正式规则。

## 需要逐项决定的玩法主题

### A. 一局结构

- 当前实验为东 / 南两圈，每圈闲局 / 庄局 / 圈主三关，每关一副；西圈是通关后的可选加赛。
- 闲局和庄局可跳，圈主不可跳；标准全打为 6 副与 5 家百宝阁。
- 仍需决定是否接受 5–8 分钟目标、五次商店密度和西圈加赛入口。
- 接受前必须记录真人完整局时长、平均跳局数、商店访问数和失败位置。

### B. 麻将规则

- 手牌数量
- 每次最多出牌数量
- 顺子、对子、刻子、杠和特殊番种
- 字牌、花牌、宝牌、风圈、听牌的取舍
- 自动识别和玩家主动宣告的边界

#### 决定：14 张结构手牌

状态：`Accepted`

玩家问题或乐趣：让玩家从第一眼就知道本轮目标是整理出一副完整胡牌，同时提供足够的组合构筑空间。

规则：

- 每个组牌阶段从 14 张结构手牌开始。
- 系统在完整的 14 张结构上检查是否满足胡牌。
- 完整胡牌触发独立于普通组合价值的 Hu Bonus。
- UI 和动画始终按最多 14 张可见麻将牌设计。

与现有系统的关系：保留原型“点击一组牌并获得强反馈”的动作，但不预先接受原型的补牌和即时结算规则。

#### 提案：1–4 张上下文操作

状态：`Proposed`

推荐范围：最少 1 张，最多 4 张。选择数量直接对应一个清楚的麻将动作：

- 1 张：弃掉一张未整理牌并摸一张，作为换牌。
- 2 张：两张相同牌组成对子并锁定，不补牌。
- 3 张：同花色连续三张组成顺子，或三张相同牌组成刻子并锁定，不补牌。
- 4 张：四张相同牌组成杠；第四张作为附加牌叠放，摸一张补张牌，使结构槽位仍按 14 张计算。

只允许一次提交一个合法动作。无效的 2–4 张组合不能提交；单张换牌始终可用。已经锁定的对子可用一张相同的未整理牌升级为刻子，刻子可再升级为杠并摸一张补张牌。

不采用 5–6 张的主要理由：它们会把“一次动作是什么”重新变成需要解释的最优组合搜索，也会同时处理多个组合，削弱逐步整理手牌的节奏。

与现有系统的关系：原型中的“出牌”分成两类含义明确的操作。单张是换牌；有效组合是整理并保留，而不是弃掉后再补回 14 张。

主要风险：玩家过早锁错组合后可能陷入无解；频繁锁定会让后半段可选牌太少；多个对子和七对等特殊胡法需要单独规则。

#### 提案：完整胡牌奖励层

状态：`Proposed`

```text
待结算筹码 = 已锁定组合价值 + 牌面强化 + 福神牌过程效果
最终胡牌得分 = 待结算筹码 × 基础胡牌倍率 × 特殊胡法倍率 × 福神牌胡牌效果
```

推荐先让锁定组合产生即时动画、音效和筹码累积，但把对盲注的主要伤害放到胡牌时结算。这样每次操作都有反馈，又不会让“胡牌”沦为可有可无。是否给予未胡牌的少量保底分，需要数值测试。

第一批需要支持的完整胡牌标签：

- 普通胡：四组面子＋一对将
- 清一色
- 一条龙
- 大三元
- 大四喜

后续可考虑七对、十三幺、混一色、四暗刻等。特殊胡法能否叠加、采用加法还是乘法、是否直接通过盲注，暂未决定。

主要待定：

1. 已锁定组合能否拆开；如果能，代价和时机是什么？
2. 每个组牌阶段允许多少次单张换牌，耗尽后如何流局？
3. 胡牌是自动触发还是玩家主动宣告？
4. 胡牌后是开始下一副 14 张，还是结束当前盲注？
5. 特殊胡法采用固定 Bonus、番数还是倍率？
6. 七对等不符合“四面子一将”的特殊胡牌如何进入锁定流程？

最小验证方式：用固定 seed 生成 10 组 14 张起手牌，纸面模拟“单张换牌、2–4 张锁组”。记录完成胡牌所需换牌数、锁组后可逆转需求、无解率和每步思考时间；再与“多张弃牌后补回 14 张”的旧方案对照。

成功信号：不懂麻将的玩家能在 45 秒内完成第一次换牌或锁组；每一步只有少量可理解的合法动作；懂麻将的玩家能主动规划四面子一将；大多数牌局能在目标换牌预算内完成或明确流局；单次决策不超过 15 秒。

#### 提案：胡牌资格与亮组得分分离

状态：`Proposed`

玩家问题或乐趣：玩家应当可以在牌型已经合法时立即胡牌，把它当作安全出口；继续亮出组合则是为了底分、福将触发和爆分，而不是一道强制完成的整理手续。同时必须支持七对等不属于“四面一将”的合法结构。

规则草案：

- 系统始终用未亮牌与已亮组共同检查完整结构。
- 普通胡是四个面子加一个对子；七对是另一条独立合法路线。
- 胡牌按钮在任一合法路线成立时立即可用，不要求把全部组合手动亮出。
- 选择 1 张换牌，选择 2–4 张亮出合法组合；两种动作都消耗统一行动。
- 亮组确认后不能重复用牌或免费拆组，并约束最终胡牌分解。
- 行动耗尽时，可胡则只允许结算；不可胡则流局。屁胡是合法但无额外番种的普通胡，不是失败保底。
- 完整胡牌的所有组合自动贡献基础分；主动亮组只计算额外奖励和灵签触发，避免为了基础分机械地把整手牌点完。
- 完全不亮组的成功胡牌获得门清金币奖励；第一次奖励型亮组后本副永久转入追分路线。

可能的风险：

- 若门清金币价值太低，已胡玩家仍会把所有能亮的组合全部亮完；价值太高则会永远直接胡。
- 七对最多产生七次对子事件，普通胡最多产生五次组合事件，通用福将可能天然偏爱七对。
- 亮组若不是胡牌求解的硬约束，会让玩家同时利用互斥分解重复得分。
- 允许得分后免费拆组会产生无限刷分和重复触发。

最小验证方式：用三副牌组成一个检查点。亮牌只取得本副临时灵签，门清胡取得商店金币；检查点结束后立即进入只含三个整局福将的小商店。准备“门清更优”“只亮一个匹配组合更优”“七对路线”三套固定牌谱。

成功信号：玩家能复述“胡牌是资格，亮组是赚分”；混合牌谱里没有固定的全亮或全不亮策略；胡牌就绪后的决定不超过 8 秒；七对与普通胡都能通过同一套操作自然完成。

#### 想法：叠杠与十四归一

状态：`Idea`，尚未实现

当构筑让完全相同的牌超过四张时，可把 4–8 张同牌一次亮成叠杠：按三张组成结构面子，多出的 1–2 张作为附张并补回等量牌；六张以上占两个开运位。一次声明只求签一次，拆成两个普通刻子则可求签两次，以形成即时强度与求签次数的取舍。14 张完全相同可测试终极胡法「十四归一」。当前牌池每种牌仍只有四张，因此第一步只做固定牌谱验证，不改持久牌库或 schema v4。完整纸面规则见 `docs/decisions/0016-same-tile-stacks.md`。

### C. 构筑系统

#### 提案：五系构筑

状态：`Proposed`

当前正式切片把内容分为五类：`灵签`是亮组后三选一的本副强化；`番谱`不占槽并提升指定番种等级；`福将`占将位并形成整局常驻引擎；`牌骨`赋予一个牌种静态材质属性；`牌印`让一个牌种在换、亮、胡等事件发生时触发。该分类仍为 `Proposed`。

牌骨回答“牌是什么”，牌印回答“牌在什么时候做什么”。同一牌种最多同时拥有一个牌骨和一个牌印。当前 `src/` 仍没有跨副持久的实体牌库，因此按一个牌种的四张同名牌共同改造，并在后续发牌中保底出现该牌种，先保证购买后能看见效果。

当前 `src/` 测试池为 19 张灵签、3 本番谱、11 位福将、2 种牌骨和 3 枚牌印。V3 的 15 张灵签与 9 位福将只保留为历史对照。分类、商店结构、触发顺序和接受条件见 `docs/decisions/0011-five-content-families.md`，当前内容见 `docs/08-content-catalog.md`。

#### 后续提案：灵签分成助势与改命

状态：`Proposed`，金色单牌定向改命切片已实现；借张、整组改花色等交互仍待验证

用户反馈指出，只加牌值或番势的灵签无法回应当前手牌最重要的麻将问题。下一版建议让灵签拥有两条核心价值：`助势`不动牌、提高本副得分；`改命`临时改变当前牌，使未胡的牌更接近成胡，或让已经能胡的牌新增清一色、一条龙等大胡番种。财签只作为低频保本选项，不再独自承担灵签的存在理由。

三签建议固定为一张助势、一张动态合法的改命和一张奇缘。第一版每副最多使用一张改命签；没有合法有效目标时，改命位回退为适配牌面的助势签，不能出现死选项。首批测试借张、移花、归一和稀有听风四种效果，完整经济、合法性、交互、存档和接受条件见 `docs/decisions/0014-charm-momentum-and-fate.md`。

#### 后续提案：银签、金签、彩签与待缘签兆

状态：`Proposed`，最小框架已实现，尚未完成真人玩法验证

灵签的功能职责与稀有度分开显示：`助势 / 改命 / 奇缘`说明做什么，`银 / 金 / 彩`说明稀有度和效果上限。普通求签首轮纸面版式为 72% 全银、25% 两银一金、3% 两银一彩，同次最多一张高阶签；问签印重抽只能换内容，不能重抽签阶。

部分奇缘会把一次性`签兆`放进单格待缘位，跨副、商店和关卡保留到下一次求签时自动消耗。当前切片已经实现`鸿运签`（下次至少一张金签，有小概率升彩）、`广缘签`（下次四选一，仍只拿一张）和用于验证彩签框架的`虹福签`；待缘位满时新签兆必须经过替换确认。签阶、存档与响应式规则已有自动验证，但概率、取牌率和是否促进机械全亮仍未经过真人试玩，因此本方案继续保持`Proposed`。完整规则见 `docs/decisions/0015-charm-tiers-and-pending-omens.md`。

#### 后续提案：三流派请将与终局爆发

状态：`Proposed`，最小切片已实现，等待真人玩法验证

用户试玩认为当前灵签与福将仍像相互独立的数值卡，缺少肉鸽的明确流派和后期无敌感。
下一版先测试游龙（顺子 / 一条龙）、雷杠（刻子 / 杠 / 碰碰胡）和七巧（对子 / 七对）三条路线。

五家百宝阁中的第 1 / 3 / 5 家改成阶段式请将台：每次展示三条路线各一位福将，只能购买一位；
第 1 次定方向，第 2 次形成引擎，第 3 次取得会把番势乘 2 或乘 3 的终局福将。
灵签同时加入金色定向改命签：选中后由玩家选择一张未亮牌，再从只包含有效改善的目标牌中选一种；
确认后真实降低成胡距离。满足流派条件才触发的金 / 彩爆发签继续负责得分上限。

这条提案不新增羁绊计数条或第五类资源，但改命签会增加一次明确的目标选择界面；完整改命流程目标不超过 8 秒。
先验证“可控改牌是否值得金签稀有度，以及卡与卡是否开始互相喂养”。
完整规则、风险与接受条件见 `docs/decisions/0020-archetype-generals-and-power-curve.md`。

- 番谱等级、稀有度、商店混池、刷新和利息。

- 牌库增删、一次性道具与局外解锁。
