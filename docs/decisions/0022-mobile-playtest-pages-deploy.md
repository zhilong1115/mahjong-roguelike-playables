# 0022 · 每次可玩更新同步部署手机试玩版

状态：`Accepted`

日期：2026-07-27

## 决定

每次完成会改变可玩体验的代码更新，并通过相关自动测试与 required 视口检查后：

1. 提交并推送当前开发分支。
2. 将 `src/` 的静态内容同步发布到仓库的 `gh-pages` 分支。
3. 等待 GitHub Pages deployment 成功。
4. 向用户提供手机可直接打开的固定试玩链接与本次 commit。

当前固定试玩地址：

`https://zhilong1115.github.io/mahjong-roguelike-playables/`

纯文档、未通过测试的实验或尚未完成的中间状态不自动部署。

## 原因

手机触控和真实横竖屏体验是本项目的核心验收方式。只在本机 localhost 完成实现，会让用户无法及时试玩，也容易让线上版本长期落后于讨论中的版本。

## 发布边界

- GitHub Pages 是开发期手机试玩渠道，不等于 YouTube Playables、TikTok Mini Games 或正式 Web 发布验收。
- Pages 继续使用自包含的 `src/` 静态文件，不引入外部字体、分析或内容服务。
- 部署失败时不能宣称已经上线；应报告失败状态并修复或说明阻塞。
- 若以后改用自动化构建或正式预览环境，应修订本记录，但仍保留“每次可玩更新给出手机试玩链接”的目标。
