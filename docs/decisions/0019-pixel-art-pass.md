# 0019 · 像素美术第一轮：标题页、牌面牌背、功能卡卡面

状态：`Accepted`（实现完成，可继续加内容，不再回到旧版式）
日期：2026-07-26

## 背景

用户试玩后提了三条视觉问题：

1. 主界面没有独立的界面和背景，logo 只是一行像素字；
2. 局内整体不够美观，牌背和牌面不好看；
3. 求签 / 商店的功能卡卡面太小，看不清写了什么。

这三条都是「看得见但不改规则」的问题，所以这一轮只动 `src/render/pixel.mjs`、
`src/ui/screens.mjs`、`src/ui/app.mjs` 的卡面构造和 `src/styles.css`，不碰任何
玩法数值、状态机或存档 schema。

## 决定

### 1. 标题页是一块独立场景，不是通用覆盖屏

- `showTitle()` 在覆盖屏里额外插一层 `.titleBg`：牌桌绒面渐变 + 交叉回纹地纹
  + 一个超大的半透明「麻」字 + 底部一排牌背拼成的牌墙（跟着当前牌组的牌背走）。
- `.titleScreen` 用自己的整块背景覆盖 `.screen` 的半透明遮罩，`screenBox` 改成
  半透明玻璃板，让背景透出来。
- logo 改为 `createLogoCanvas()` 画的像素牌匾：朱漆底 + 双层金框 + 削角，
  「天胡」两个大字用黑描边压金面，下面挂一条写 `TIANHU` 的绿飘带。
  它是一张 canvas，`image-rendering:pixelated` 放大后仍然是硬像素。

### 2. 牌面 = 象牙面 + 玉色托板，牌背 = 同一套立体规则

- `tileBody()` 给牌加了削角、象牙面、面下缘的暗色弧面，以及底部 6px 的**玉色托板**。
  真麻将牌就是象牙面压在竹背上，这一条是整张牌「立起来」的关键。
  因为底部被托板占掉，牌面图案的中心统一上移到 `FACE_CY = 20`。
- `backSource()` 从平铺花纹改成和牌面同构：外框 → 内嵌细线框 → 四角小方块 →
  中央纹章 → 同一条玉色托板。四款牌背各有一个可辨认的纹章（铜钱 / 套菱 / 回字 / 北斗）。

### 3. 密笔画的字用两级半调，不是纯 1-bit

原来所有字模都按 alpha 阈值硬化成 1-bit。这对「一 / 二 / 中 / 南」很好，但
`萬`、`發`、`東` 在 34×46 的牌面上会糊成一坨；单纯调高阈值又会把笔画打断。

所以 `harden()` 增加 `levels` 参数：`levels = 2` 时把 alpha 分成 0 / 130 / 255 三档，
保留一档半调。密笔画字（萬 / 發 / 東）走两级，其余仍然是纯 1-bit + 白色刻痕垫底。
`glyph()` 同时支持 `outline` / `drop`，logo 的描边就是靠它。

### 4. 功能卡卡面按「竖版卡」重做，并且明显放大

| 位置 | 之前 | 现在 |
|---|---|---|
| 求签 `.charmPick` | 132px 高，印章 30×38 | 244px 高 / 212px 宽上限，印章放大一倍 |
| 商店 `.shopCard` | 136×~120 | 174×214，价格牌上浮 |
| 百牌谱 `.libraryCard` | 148px 列 / 158px 高 | 184px 列 / 210px 高 |

- `cardNode()` 增加 `sealScale`，求签 / 商店 / 图鉴一律用 2 倍印章。
- `createSealCanvas()` 从「方框 + 字」升级成牌匾：顶部系别色带、双层内框、四角刻痕、
  下缘阴影、削角，字带白色刻痕。
- 卡面加一层 `::before`：顶部高光 + 斜向细纹，让纯色块变成「印出来的卡」。
- 求签卡的职责标签变成左上角的浅色胶囊，签阶变成整行深色带；正文 11px、
  底部信息带用一条分隔线压住，读起来是卡而不是一段文字。
- `.charmPick` 加 `max-width`：不加的话三签一排会被拉成横条，读感完全不像卡。

## 影响与验收

- 规则、数值、存档 schema 全部未动；`node --test tests/*.test.mjs` 127 项全绿。
- `node tests/src-viewport-smoke.mjs` 六视口全绿：无裁切、无遮挡、无页面横向滚动，
  最小可点尺寸仍 ≥44×48px。求签卡从原来的 112–132px 高变成 193–244px 高。
- 矮横屏（844×390）单独降一档：求签卡 176px 高、宽 170px 上限，商店卡 150×180，
  保证 390px 高度里标题 + 卡 + 按钮仍然一屏放得下。

## 没做的事

- 牌桌上的发牌 / 亮组动画没有改，仍是 `0010` 那一套。
- 番谱 / 牌骨 / 牌印目前仍共用系别单字做印章图（同系多张卡会重字），
  等内容定型后再逐张给专属字。
- 没有做 logo 的动效（呼吸、闪光），先确认静态版式。
