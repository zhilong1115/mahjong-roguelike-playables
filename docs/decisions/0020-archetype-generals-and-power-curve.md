# 0020 — 三流派福将与后期爆发曲线

状态：`Proposed`（用户确认方向，最小切片待真人试玩）

日期：2026-07-27

## 要解决的问题

当前灵签和福将虽然能稳定加牌值、番势或金币，但多数效果彼此独立。玩家很难在六关内说出
“我这局是游龙流 / 雷杠流 / 七巧流”，后两关也缺少肉鸽应有的规则联动和压倒性爆发。

本切片的成功信号：

- 第一家百宝阁后，玩家能用一个短标签说出自己的路线。
- 东圈结束前出现第一段两卡联动，南圈圈主前拿到一次终局级效果。
- 后两关的成型路线明显强于无构筑基线，并能在结算步骤里解释爆发来源。
- 灵签不再全部是加分牌；金色改命签会让玩家亲自选择一张牌和一个合法目标，并真实减少“还差几张”。
- 三选一平均仍以 5 秒内为目标，教程不增加一整页规则说明。

## 提案

### 三条主流派

| 流派 | 核心牌面 | 玩家记法 | 后期爆发 |
|---|---|---|---|
| 游龙 | 顺子 / 一条龙 | 多做顺子、整理连续数字 | 三顺以上让番势翻倍 |
| 雷杠 | 刻子 / 杠 / 碰碰胡 | 相同牌越多越好 | 三组刻杠以上让番势翻倍 |
| 七巧 | 对子 / 七对 | 见对就留 | 七对终局将番势变为三倍 |

福将卡增加 `archetype` 与 `stage`：第一阶段给方向，第二阶段形成引擎，第三阶段改变结算规则。
四个将位仍保留，玩家可以放入一张经济或通用福将进行混搭。

### 三次请将

五家百宝阁里，第 1 / 3 / 5 家改为“请将台”：各展示游龙、雷杠、七巧一位福将，只能购买其中一位。
三个节点分别提供阶段 1 / 2 / 3 福将。第 2 / 4 家保留番谱、牌骨、牌印和牌帖等长期商品。

请将台不能刷新，避免通过刷新改变固定阶段，也避免玩家在高价值三选一里反复读卡。
玩家可以跳过购买，但不会自动获得福将；金币路线与成型速度继续构成取舍。

### 灵签分工

- 银签：立即有用，以稳定牌值、金币和低复杂度助势为主。
- 金签：包含引路、聚雷、红线三张定向改命签，以及把某条流派从加牌值推进到加番势的助势签。改命签选中后先选择一张未亮牌，再选择它要变成的牌种；界面只显示会真实减少成胡距离、且不会造出第五张同牌的合法结果。没有合法目标时不进入本次候选池。
- 彩签：只在满足清楚条件时把当前番势乘 2 或乘 3，不做同名银签的单纯大数值版。

定向改命保留实体牌 id，只改变该牌本副的牌种；牌骨与牌印仍按变更后的当前牌种结算。
取消目标选择会返回原来的三签界面，确认后才取得灵签并提交改牌。合法目标由手牌状态唯一决定，不引入新的随机源。

### 爆发结算

结算步骤增加 `multFactor`，在原有加法番势之后执行乘算。卡面必须明确显示“番势 ×2 / ×3”，
动画步骤也必须显示乘算前后数值。最终公式仍显示为 `牌值 × 番势`，只是番势可以被终局卡翻倍。

## 与现有系统的关系

- 不改变 14 张结构、亮组占开运位、三签选一、五系分类和四将位。
- 继续使用 `CONTENT_LIBRARY` 作为唯一卡牌数据源。
- 请将台属于现有百宝阁的特殊货架，不新增平台或存档服务。
- 旧存档中的五位福将 id 保持有效；新增字段是内容元数据，shop 对象沿用 schema v4 的透传结构。
- 圈关结构 `0017` 仍是 `Proposed`；本切片利用当前六关验证强度曲线，不把六关本身升级为 Accepted。

## 替代方案

1. **只扩充更多线性加分卡**：实现快，但不能解决“没有流派”和“后期不无敌”。
2. **新增独立羁绊计数系统**：更像阵容构筑，但会增加一套需要教学的隐藏阈值；首轮不做。
3. **让所有金 / 彩签跨副保留**：长期感强，但会模糊灵签与福将职责，并放大存档和触发复杂度。

## 风险与回退

- 固定请将台可能让每局路线过于稳定；若重复度过高，可在每个阶段为每条流派扩充 2–3 位同阶候选。
- 番势乘算可能让目标分失去意义；先保留现有目标，只记录成型路线与无构筑路线的倍率差，再重标六关。
- 定向改命可能让玩家稳定完成关键牌；因此升为金签、每张只改一张、仍以一个开运位为代价，并且只在本来存在改善目标时出现。
- 若移动端三张大卡阅读仍超过 8 秒，阶段 1 卡只显示一句核心规则，详细说明进入百牌谱。

## 最小验证

使用固定牌谱分别验证三条路线：

1. 第一家请将台提供三个阶段 1 方向，购买后其路线在后续结算可见。
2. 改命签只显示合法原牌和目标牌；确认前不改变状态，确认后 `tilesToChange` 至少下降 1，取消可返回三签。
3. 阶段 1 + 2 + 3 同路线在目标牌型上产生乘算步骤，分数显著高于只持阶段 1。
4. 三次请将只能各买一位，刷新不会绕过限制，存档恢复后选择状态不丢失。
5. required 六视口的请将台、普通商店和求签均无关键裁切。

通过上述自动验证只代表切片可玩；是否真的“有流派、后期无敌而且还想再来一局”必须由真人完整试玩决定。
