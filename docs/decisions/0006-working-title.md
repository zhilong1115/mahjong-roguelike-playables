# 0006 — Working Title: 天胡 / TIANHU

状态：`Proposed`

日期：2026-07-25（2026-07-25 第二轮改名）

## 决定

```text
天胡
TIANHU
```

「天胡」是麻将里开局即成牌的极致好运，也是流行语「天胡开局」的来源。它属于番种名这一层语言，和游戏内的番种、福将、灵签是同一套词汇，不需要额外解释。英文直接用拼音 `TIANHU`，在海外平台当专有名词使用，不做意译。

名称不沿用「小丑牌」、`MAHJONGTRO` 或任何第三方游戏的品牌表达。

## 替代方案与落选原因

| 候选 | 落选原因 |
|---|---|
| 十四福将 / Lucky Fourteen（上一版工作名） | 描述性强但偏长偏软，四个汉字在平台小图标下吃亏；`Lucky Fourteen` 作为英文名几乎没有独特性 |
| 通天胡 | 独特性和商标强度都优于「天胡」，但三字更长，且「通天」的语感离现金棋牌 App 更近 |
| 牌开富贵 | 吉语系最强的一个（由「花开富贵」改造），四字偏长 |
| Tessera（拉丁语「牌 / 筹码」） | 与 Balatro 的取名逻辑同构，但不专指麻将；且 Tessera Technologies 等在先使用较多 |
| Mangan / 满贯 | 麻将玩家易懂，但偏日麻语境，且在德语、土耳其语里是「锰」 |
| Pung、Jongleur、雀仙、开运牌馆、百福图 | 各有一处不合：读感、发音门槛、或与爆分气质不符 |

## 已知风险（用户已知悉并确认继续）

1. **`TIANHU` 与日麻平台「天鳳 / Tenhou」读音接近**，海外麻将圈可能误认或混淆。
2. **「天胡」是通用麻将术语**，商标显著性弱，很可能无法在核心类目上获得排他保护；「天胡开局」作为流行语也会稀释搜索结果。

如果后续法务或市场检查判定这两条不可接受，回退顺位是「通天胡 / TONGTIAN」，它保留同一语感但独特性更高。

## 后果

- V3 试玩版、README、愿景文档统一使用「天胡 / TIANHU」。
- 归档原型不改名：`prototype/legacy-demo.html`（标题 `麻将小丑牌 MAHJONGTRO`）、`prototype/v2-run-shop-demo/`、`prototype/progressive-meld-demo/` 保持原样，作为历史对照。
  其中 `MAHJONGTRO` 属于第三方品牌的派生表达，**不得用于任何对外发布物**。
- 工作名不等于商标冻结。

## 仍需核查

- 中国大陆、美国、欧盟在第 9 类和第 41 类的商标检索。
- 域名与 App Store、Google Play、YouTube Playables、TikTok 的名称占用。
- 「天胡 / TIANHU」在日麻受众里的混淆程度，必要时英文另起。

## 接受条件

- 玩家能记住并复述名称。
- 名称与十四张组牌、爆分、福将构筑的核心体验相符。
- 法律与平台命名检查无高风险冲突。
