# 0017 — 六关短局与高频百宝阁节奏

状态：`Proposed`（用户确认方向，等待最小切片与真人试玩）

日期：2026-07-26

实现目标：`src/`

## 玩家问题

`0013` 的三圈九关、每关最多两副让完整路线达到最多 18 副。即使每关后都有百宝阁，玩家仍要花太多时间打牌，构筑奖励的反馈频率不够高。用户明确反馈“三圈九关太慢”，更希望频繁进入商店或抽卡。

本提案借鉴成熟构筑游戏的“短战斗 → 商店 → 变强”节奏，但不复制第三方名称、素材、数值或整体视觉。

## 提案

标准短局改为：

```text
开局选择牌组
→ 东圈：闲局 → 百宝阁 → 庄局 → 百宝阁 → 圈主 → 百宝阁
→ 南圈：闲局 → 百宝阁 → 庄局 → 百宝阁 → 最终圈主
→ 短局通关；可选择进入西圈加赛
```

- 标准局为东 / 南两圈，每圈闲局、庄局、圈主三关，共 6 关。
- 每关只打一副，胡牌分数达到目标即过关，失败则本局结束并可试玩重试。
- 每个打赢的非最终关后进入百宝阁；全打标准局共 5 家商店。
- 闲局和庄局仍可跳，跳局得到手气，但失去本关得分、过关金和商店。
- 南圈圈主通关后先算一次完整胜利；西圈保留为可选加赛，共 3 关、2 家额外商店。
- 开局免费三选一、商店签筒 / 牌包与新的金币出口属于后续切片；本轮先只验证关店交替节奏。

## 初始数值

第一轮固定牌谱目标只作为自动测试与真人试玩起点：

| 圈 | 闲局 | 庄局 | 圈主 |
|---|---:|---:|---:|
| 东圈 | 400 | 550 | 700 |
| 南圈 | 800 | 1350 | 2200 |
| 西圈加赛 | 1000 | 1450 | 2400 |

旧九关两副目标及 40 局 × 4 策略数据保留在 `0013` 和对应模拟记录中，只作为历史对照，不能用来证明六关版本平衡。

## 存档与兼容

- `ANTES` 保留西圈数据，标准局另存当前启用圈数。
- 新局默认启用两圈；选择加赛后扩到三圈。
- 旧 schema v4 存档若已经位于西圈，恢复时继续按三圈处理；东 / 南圈旧档按新的两圈标准局继续。
- 当前仍使用 schema v4 的可选字段，不破坏旧档读取；若后续签筒引入新持久状态，再单独升级 schema。

## 代价与风险

- 关卡减半后，长期商品只有 1–5 关的兑现窗口，价格和效果都要重跑。
- 五家商店可能仍不够消耗门清金币，也可能因收入减少突然买不起当前商品。
- 每关一副会放大坏牌或操作失误；保底可解发牌、可见牌墙和试玩重试必须保留。
- 如果亮组求签次数过多，虽然关卡减少，单副仍可能拖慢；需要记录每副实际求签数。
- 西圈加赛不能成为默认流程的伪装，否则短局目标没有真正实现。

## 最小验证

1. 固定 seed 自动跑标准六关与西圈加赛，确认分别出现 5 / 2 家商店。
2. 比较门清、亮两组、尽量全亮、跳闲局四条路线的通关率、金币和商店购买数。
3. 真人记录标准局总时长、每副求签次数、商店停留时间和是否主动进入西圈。

## 成功与撤回条件

成功信号：标准局中位时长 5–8 分钟；玩家感到“每打一副就能构筑”；至少完成 3 次有意义购买；西圈进入率不是接近 0% 或 100%。

撤回或修订信号：六关内长期构筑来不及成形；商店变成无钱可买的空步骤；单副失败过于随机；或大多数玩家仍认为进入商店太慢。
