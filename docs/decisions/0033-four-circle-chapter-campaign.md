# 0033 · 四圈章节、章节大 Boss 与四星重玩

状态：`Proposed`（章节层级已经明确；圈数、时长、奖励与失败规则仍需原型验证）

日期：2026-08-02

## 玩家问题

当前游戏进入新局后直接开始东 / 南圈 Run。虽然每圈已经有`闲局 → 庄局 → 圈主`的小循环、
圈主也有特色规则，但玩家看不到更大的闯关目标：为什么要继续养成这套福将、最后要挑战谁、
通关后为什么还值得再来一次。

目标不是替换现有三关小循环，而是在它外面建立一层真正的章节：玩家用数圈时间养成一套构筑，
最后用成型流派击败章节大 Boss；通关后再用四星任务推动重复挑战。

## 已明确的层级

```text
标题页
→ 章节选择
→ 进入一个大关卡 / 章节
   ├─ 第 1 圈：闲局 → 庄局 → 圈主
   ├─ 第 2 圈：闲局 → 庄局 → 圈主
   ├─ 第 3 圈：闲局 → 庄局 → 圈主
   ├─ 第 4 圈：闲局 → 庄局 → 圈主
   └─ 章节大 Boss
→ 章节结算：检查四项任务，授予 1–4 星
→ 解锁下一章节或重打本章补星
```

- `闲局 → 庄局 → 圈主`继续是每圈的基本节拍；圈主是小 Boss，不等于章节最终 Boss。
- 四圈是首轮候选，不是冻结数字。若完整章节明显超过目标时长，可以调整圈数、商店频率或单圈节奏，
  但不能退回“标题页直接进入一段没有章节目标的无限 Run”。
- 章节大 Boss 必须是独立节点，拥有明确可预告的章节机制；不能只把圈主换名或单纯提高目标分。
- 第一版先做少量完整章节，不用大量空节点假装已有内容。

## 构筑成长节奏

章节长度应服务于福将流派逐步成型，而不是单纯增加战斗数量：

| 阶段 | 玩家体验 | 主要构筑作用 |
|---|---|---|
| 第 1 圈 · 起势 | 看见本章环境并选择路线 | 第一位路线福将、基础灵签或开局改造 |
| 第 2 圈 · 成势 | 同路线组件开始互相触发 | 第二位福将、番谱或牌种改造 |
| 第 3 圈 · 成型 | 核心循环成立并第一次爆发 | 终局福将、关键金签或乘算组件 |
| 第 4 圈 · 冲顶 | 完整套路追求上限 | 补短板、彩签、高风险强化或第四将位 |
| 章节大 Boss | 检验这套构筑 | 要求玩家把本章学到的策略真正打出来 |

现有 `0020` 的起势 / 成势 / 终局三阶段福将可以直接承担前三圈成长。第四圈优先作为成型后的爽感与补强阶段，
不急着为了凑四圈额外设计第四套固定福将。

## 四星评价

每章最多四星，所有条件在开打前可见：

1. **通关星**：击败章节大 Boss。拿到这一星即可解锁下一章，普通玩家不会被附加任务卡住。
2. **分数星**：达到本章总分或大 Boss 分数目标。
3. **章节星**：完成与本章主题相关的任务，例如累计开杠、完成清一色或触发指定路线。
4. **高手星**：完成不重试、限制锦囊、保留资源等更难条件；一次只使用一条清楚的挑战轴。

附加星优先用于展示完成度、解锁新卡内容或外观，不提供永久数值碾压。玩家可以通关后继续重打补星，
不必一次同时完成所有任务。

## 多章节与卡池

- 每个章节由`公共基础卡池 + 本章特色卡池`组成，避免进入新章后所有已经学会的卡牌突然消失。
- 章节可以改变特色灵签 / 福将 / 牌骨出现率、圈主池、章节任务、背景与最终 Boss。
- 通关可以把少量新卡加入后续章节或全局 Library；具体采用解锁后扩池、章节限定还是开局选择，后续单独决定。
- 第一批只需要 2–3 个有清楚差异的章节。内容差异必须来自玩法主题，不用先靠大量美术换皮撑数量。

## 检查点与短时游玩

四圈加大 Boss 可能比当前六关短局明显更长。为了仍适合 YouTube Playables、通勤和排队场景：

- 每圈结束后必须是稳定存档检查点，退出后可以从下一圈继续。
- 单圈仍要形成一个短小完整体验：三局、圈主结算、一次明显的构筑成长。
- 完整章节目标时长暂定 12–20 分钟，只是测试区间；单圈目标 2–4 分钟。
- 失败后从本局、当前圈还是章节开头重来尚未决定；可先允许重试，并把“不重试”作为第四星条件测试。

## 与现有 `0017` 的关系

`0017` 的东 / 南两圈六关仍是当前可玩实现和快速测试切片。`0033` 提议把这套小循环包装进章节，
并把现有西圈加赛重新考虑为正式圈、隐藏圈或通关后挑战。没有完成时长与存档原型前，`0033` 不自动替换 `0017`。

## 尚未决定

1. 首章最终采用 3 圈还是 4 圈；四圈是否会把构筑选择拖成重复劳动。
2. 圈内仍然每关进商店，还是把部分商店集中到圈末。
3. 章节大 Boss 是一副牌、连续两阶段，还是带独立资源条。
4. 失败重试位置、重试代价以及它与四星任务的关系。
5. 星星具体解锁章节、卡牌、外观还是自由模式规则。
6. 首批章节主题、特色卡池与 Boss 机制。

## 最小下一步

先不批量制作章节。做一份首章节奏表或不可持久化原型，复用现有东 / 南 / 西内容并补一个占位第四圈和章节 Boss，
只验证四件事：

- 一圈和完整章节分别需要多久。
- 第 3 圈前能否形成路线，第 4 圈是否真的提供“后期无敌”的爽感。
- 章节大 Boss 是否像构筑终考，而不是多打一场高分关。
- 四项任务能否在开打前读懂，并产生重打一遍的意愿。

通过后再进入章节地图、四星存档和首批内容制作；若过长，先调圈数与商店节奏，不否定章节层本身。
