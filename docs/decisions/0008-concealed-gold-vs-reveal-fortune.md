# 0008 — Concealed Gold vs Reveal Fortune

状态：`Proposed`

日期：2026-07-25

后续提案：用户试玩后希望把固定两次亮牌改为六个开运位、每次亮牌后三签选一、空位线性兑换金币。该下一轮方向记录在 `0009-six-fortune-slots-and-three-choice-draft.md`；本记录保留为 V2 Demo 的实验基线。

## 要解决的问题

玩家已经能够胡牌时，需要一个容易理解、长期有意义的理由决定立即胡还是继续亮牌。单纯给亮牌加分会让所有正收益组合都成为必点动作；单纯奖励速胡分数又无法自然连接商店和 Roguelike 构筑。

## 提案

建立两种奖励路线：

```text
门清路线：完全不主动亮组 → 稳定金币 → 商店购买整局福将
开运路线：主动亮组 → 本副临时灵签 + 更高得分 → 少量基础金币
```

两类功能效果明确分层：

- **灵签**：亮牌路线取得，只在当前一副牌生效，结算后消失，不可出售。
- **福将**：通过金币在商店购买，拥有有限槽位并在整局中持续生效。

这样亮牌提供立刻可感知但不会永久雪球的战术收益，金币提供延迟但可控的长期构筑。

## 一副牌的结算规则

- 每副开始时 `cleanHuEligible = true`。
- 第一次确认任何奖励型亮组后立即变为 `false`，本副不能恢复；取消选择或系统在结算时自动展示胡牌结构不影响它。
- 成功胡牌不另设隐藏的基础金币；当前实验按亮组次数直接产生 3 / 1 / 0 金。
- `cleanHuEligible` 仍为真时获得完整的 3 金门清奖励，但不取得灵签。
- 进入亮牌路线后，每次成功亮组取得一张本副灵签；当前 V2 Demo 同一副最多两张。
- 本副胡牌后，分数与金币仍进入本轮待结算区；只有三副牌全部胡牌且累计分达到目标时才正式入账。
- 本轮任一副流局、退出或重试时，本轮尚未入账的奖励全部作废，不能反复刷前两副。
- 功能牌选项、牌墙和奖励由 seed 决定，重载不能刷新结果。

## 最小垂直切片

为了在两分钟左右感受到两个奖励的用途，首个 V2 Demo 使用：

```text
三副牌累计分数
→ 每副选择门清金币或亮牌灵签
→ 达到本轮目标
→ 立即进入三选一商店
→ 购买一个整局福将
→ 再打一轮，感受构筑效果
```

实验参数：

| 行为 | 金币 | 额外收益 |
|---|---:|---|
| 完全不亮组后胡 | 3 | 门清路线，无本副灵签 |
| 亮 1 组后胡 | 1 | 一张本副灵签与亮牌加分 |
| 亮 2 组后胡 | 0 | 两张本副灵签与更多亮牌加分 |

首版暂定每副最多主动亮两组，用来迫使玩家选择最匹配灵签的组合，并避免一副已经合法的手牌再次变成五到七次机械点击。这个上限只是实验参数，连碰或特殊福将以后可以提高它。

V2 Demo 首批本副灵签使用四张固定效果：

- **顺风签**：结算时每个顺子增加 10 底分。
- **刻福签**：结算时每个刻子或杠增加 15 底分。
- **双喜签**：结算时每个对子增加 5 底分。
- **余裕签**：胡牌时每个剩余行动增加 8 底分。

V2 Demo 首批商店福将与价格：

- **青龙使（2 金）**：整局每个顺子增加 10 底分。
- **同心娘（5 金）**：整局每个对子增加 8 底分。
- **镇字将（8 金）**：整局每个字牌刻子或杠增加 20 底分。

试玩从 2 金开始；第一轮目标为 1100 分，第二轮目标为 1900 分。第一轮完全门清的三副牌可赚 9 金，因此三件商品都可选择；全程亮两组的追分路线只保留起始 2 金，仍能购买最低价福将并继续第二轮。这些都是可测试参数，不是最终平衡。

具体分数、商店价格和关卡目标必须通过模拟与试玩确定，不因本记录成为正式平衡。

## 为什么不让亮牌直接抽永久福将

- 一副最多五至七个结构组，逐组抽永久卡会迅速填满槽位并产生滚雪球。
- 中途反复三选一会打断 20–45 秒的短局节奏。
- 永久卡若能出售，会让亮牌路线绕过金币路线，同时获得卡牌与经济。
- 临时灵签让玩家当副就能感到奖励，永久福将仍由商店和金币控制。

## 主要风险与护栏

- **永远门清**：后续关卡目标必须让纯基础分逐渐不够，同时灵签要与可见牌面产生明显匹配机会。
- **永远亮牌**：门清金币必须能在最近一次商店兑现为可控、可见的长期能力。
- **七对多触发**：每次主动亮组最多抽一张、首版最多两次主动亮组，避免七对凭七组天然多抽卡。
- **失败刷奖励**：单副胡牌只把奖励提交到本轮待结算区；整轮过关才入账，失败全部清空。
- **先亮后撤拿两边**：首次奖励型亮组永久取消当副门清资格，即使拒绝灵签或以后出现特殊拆组效果也不恢复。
- **读档刷新**：奖励选项和领取状态使用 `runId + encounterId + handId` 固定并防重复结算。

## 替代方案

1. 每少亮一组多给一部分金币：梯度更细，但结算说明更重，也容易让七对与普通胡不公平。
2. 亮牌直接抽整局永久卡：反馈强，但永久构筑增长过快，商店价值下降。
3. 剩余行动直接换分：易于单手 Demo 平衡，但没有建立用户想要的商店经济。

## 接受条件

- 玩家能复述“门清拿钱、亮牌开运”。
- 三副牌中至少出现一次立即胡和一次主动亮牌，而不是固定选择同一路线。
- 玩家在两分钟内实际用金币买到一个福将，并在下一轮看到效果。
- 本副灵签不会造成流程中断、无限触发或永久卡雪球。
- 七对与普通胡不会因为可亮组数量不同而获得不同数量的永久构筑奖励。
