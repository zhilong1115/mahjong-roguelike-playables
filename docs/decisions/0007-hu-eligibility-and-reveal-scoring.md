# 0007 — Separate Hu Eligibility from Reveal Scoring

状态：`Proposed`

日期：2026-07-25

## 方向确认

用户确认认可“合法牌型可直接胡、主动亮牌用于追求更好收益”的方向，并进一步提出：完全不亮牌的胡牌获得金币用于之后购物；亮牌则可能抽取功能牌、帮助本次胡得更好。

因此本记录从 `Idea` 升为 `Proposed`。具体数值、亮牌上限和奖励频率仍是实验参数，未达到 `Accepted`。

## 要解决的问题

V1 要求玩家手动锁满“四面一将”才能胡，造成三个问题：

- 四面一将成为唯一界面结构，七对等特殊结构无法自然进入。
- 已经完整胡牌的玩家仍要机械地把每组逐一归位。
- 锁组同时承担合法性、进度、底分和福将触发，难以形成真正选择。

目标是让胡牌成为玩家随时可以选择的安全出口，让亮组成为为了爆分主动承担机会成本的动作。

## 提案

把规则拆成四层：

1. **胡牌资格**：完整 14 张结构能否构成一种合法胡牌。
2. **整副基础分**：最终合法分解中的全部组合自动提供基础分。
3. **胡法倍率**：合法胡牌具有哪些番种标签。
4. **亮牌与构筑效果**：主动亮组触发额外得分和本副功能牌；门清胡提供商店经济。

流程草案：

```text
14 张结构牌
→ 1 张换牌，或亮出 2–4 张合法组合
→ 每个动作消耗 1 次统一行动
→ 牌型合法后可随时主动胡牌
→ 继续亮组可触发灵签与额外得分，但会放弃门清金币奖励
→ 行动耗尽：可胡则结算，不可胡则流局
```

## 胡牌路线

首批至少支持：

- **普通结构**：四个顺子、刻子或杠，加一个对子。
- **七对结构**：七个不同牌面的对子；V2 Demo 采用严格七对，四张相同不算两个对子。是否长期保留仍待试玩决定。

屁胡指合法普通结构但没有额外番种，不能用来代替失败。四个刻子或杠加一个对子属于碰碰胡；白、发、中三个刻子或杠属于大三元；东、南、西、北四个刻子或杠属于大四喜。杠本身不是大三元或大四喜，但对应的三元牌杠或风牌杠可以满足其面子条件。

同一副牌若同时存在多种合法分解，系统需要枚举候选并采用明确、可解释的计分选择，不能随机判定。

## 亮组规则边界

- 已亮牌移动到独立的亮组行，但仍属于玩家的 14 张结构。
- 已亮组不能重复使用，并成为最终胡牌分解的约束。
- 确认前可以取消；确认并获得收益后，首版不允许免费拆回。
- 杠的第四张是附加牌，不占结构槽位，并立即补摸一张。
- 已亮顺子、刻子或杠不能进入七对路线。
- 七对的对子事件数量高于普通胡，底分和福将触发需要单独平衡。

## 立即胡与继续亮组

如果亮组有正收益，而直接胡没有独立价值，那么“已经能胡却立即胡”永远是劣势。用户选择用跨手经济制造机会成本：门清胡获得金币，亮牌胡获得本副功能牌和更高分。

基础计分与路线奖励分开：

```text
胡牌得分 =
（整副胡牌基础分 + 亮牌额外分 + 本副灵签效果）× 胡法倍率

整局奖励 =
门清胡 → 较多金币，用于购买整局福将
亮牌胡 → 本副灵签与更高得分，只获得少量基础金币
```

所有牌型基础分在胡牌时根据最终合法分解自动计算，不要求玩家为了拿到基础分把四面一将或七个对子逐组点完。主动亮牌只负责额外奖励、灵签触发和路线选择。

V2 Demo 的测试值是：胡牌底分 100，对子 / 顺子 / 刻子 / 杠分别为 10 / 20 / 30 / 50 底分；七对、碰碰胡、一条龙各增加 0.5 番势，清一色增加 1，大三元增加 2，大四喜增加 3，所有番势采用加法后一次相乘。选择一个可亮组合时，界面应显示下一张灵签及若当前已经能胡则显示预计分数变化。

## 示例

用户提出的数值示意可以表达为：

- 每个刻子提供 10 基础分。
- 对子提供 5 基础分。
- 四个刻子与一个对子在最终胡牌时自动产生 45 结构基础分，无论是否逐组亮出。
- 该结构属于碰碰胡，不是屁胡，因此还会获得碰碰胡倍率。

是否值得主动亮出其中一组，取决于当前本副灵签能否让该组产生足够额外分，以及玩家是否愿意放弃门清金币。

## 主要风险

- 门清金币价值过低会退化成永远亮牌；过高会退化成永远立即胡。
- 已得分组合若能免费拆回，会产生重复计分和重复触发。
- 七对拥有更多组合事件，通用 `onReveal` 效果会天然偏向七对。
- 亮错组合可能同时堵死普通胡与七对，需要提交前预警或禁止。
- 升级对子、刻子和杠容易重复计分；首个 V2 Demo 可暂不支持升级。

## 最小实验

使用三套固定牌谱：

1. **门清局**：当前灵签与手牌不匹配，保留门清金币更优。
2. **灵签局**：一个组合与当前临时灵签高度匹配，部分亮组后胡更优。
3. **七对局**：能直接七对胡，也能亮出若干对子换取收益。

界面必须同时显示“现在胡的预计得分”和“亮出本组后的预计变化”。试玩记录直接胡、部分亮组、全部亮组的比例，以及玩家能否解释自己的选择。

## 接受或放弃条件

接受条件：

- 玩家能理解胡牌不要求全部亮组。
- 混合牌谱中不存在固定的全亮或全不亮策略。
- 胡牌就绪后的选择通常不超过 8 秒。
- 普通胡、七对与字牌大番可以共用同一套界面和规则求解。

放弃或重做条件：

- 玩家仍把亮组误解为胡牌必要步骤。
- 门清金币与亮牌灵签只增加结算负担，没有产生可感知选择。
- 七对与普通胡的事件数量差异无法在简单规则内平衡。
