# 0032 · 成品化水墨外层与牌桌层级打磨

状态：`Rejected`（手机试玩认为不如上一版；表现代码已完整回退）

日期：2026-08-01

## 玩家问题

现有原创水墨背景、麻将牌和卡图已经建立了美术方向，但界面仍像功能完整的网页 Demo：

- 标题页把 Logo、牌和全部按钮装进一个居中的矩形面板，没有“进入一款游戏”的场景感。
- 选关页是三张并排功能卡，看不出路线推进、当前关和圈主压轴的关系。
- 局内每块信息都使用同样粗的黑框和外投影，重要内容与辅助内容抢同一层级。

成功信号不是“多加纹理”，而是玩家在三秒内先看到品牌与主行动、当前路线与圈主、手牌与可用锦囊；
同时画面仍保持宣纸、松烟、旧木、温玉和朱砂的统一世界。

## 被测试方案（已撤回）

### 1. 标题页从居中面板改为完整游戏扉页

- 横屏使用左右构图：左侧 Logo、短标语与五张麻将牌形成品牌场景，右侧用独立册页承载开始 / 继续和辅助入口。
- 竖屏回到上下构图；主行动仍在首屏内，触控区不缩小。
- 背景继续使用本地原创水墨图，不引入网络字体、玻璃拟态或第三方视觉语言。

### 2. 现有三关选关改成水墨路线

- 不改变 `0017` 的关卡数量、跳局规则或奖励，只重画现有闲局 → 庄局 → 圈主的空间关系。
- 三个节点用墨线连接，并明确显示`当前 / 待战 / 已过 / 已跳`；圈主节点使用独立朱砂材质。
- 当前节点仍保留原来的开打与跳局按钮；自动化依赖的 `.blindCard.current .blindActions` 交互契约不变。
- 这不是 `0031` 的正式章节地图，不显示虚假的星级、解锁或局外进度。

### 3. 牌桌从“四块仪表盘”收成一套实体牌具

- 左侧四个分组继续保留，但共同落在一根旧木状态轨中；内部以细分隔线取代重复粗框。
- 开运 / 锦囊架、中央牌桌、操作按钮与手牌托条使用不同厚度与材质，形成前后层级。
- 手上的麻将牌和可主动点击的锦囊保持最高局部对比；背景、空槽与辅助文字降低对比。
- 动效只给主按钮、当前关和稀有签 1–2 个焦点；继续尊重 reduced-motion。

2026-08-01，用户试玩后直接判断“这个界面不如上一版”。这满足本记录的回退条件：

- 标题扉页、三关水墨路线、统一木质状态轨及其专属视觉测试全部撤回。
