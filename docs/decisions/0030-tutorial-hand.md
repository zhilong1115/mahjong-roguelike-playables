# 0030 · 教学关：一副固定牌走完全部基础操作

状态：`Accepted`（实现完成）
日期：2026-07-31

2026-08-01 修订：用户真机认为“加载完成就被教学接管”不像进入一款完整小游戏。
教学内容不变，但入口改为：**永远先显示标题页；玩家点“开始新局”时，只有没有旧存档、也没有教学完成标记的首次玩家进入教学；教学完成或跳过后直接开始新局。**
有旧存档或已经完成 / 跳过教学的玩家点“开始新局”时直接开局。标题页的“教学”按钮仍可随时重看，手动重看结束后返回标题页。

## 背景

用户要求：第一次打开游戏应该像一般小游戏那样，先进一个教学关，一步一步介绍每样东西是什么，
稍微快速地打完之后再进主界面。

在此之前只有一页静态的「玩法」文字说明，玩家要先看完一屏字才知道亮组是什么。

## 决定

### 1. 用真界面走一副固定牌，不做假演示

教学关就是正式牌桌，走完一整副：**亮组 → 求签 → 换牌 → 胡牌 → 结算**。
玩家学到的操作就是正式局里的操作，不需要二次学习。

十步，除三步需要动手外都是一次点击：

| 步 | 锚点 | 讲什么 |
|---|---|---|
| 1 | 居中 | 这是什么游戏 |
| 2 | `#handZone` | 14 张手牌与胡牌条件 |
| 3 | `#distV` | 还差几张 |
| 4 | `#btnReveal` | **亮组**（需要动手） |
| 5 | `#draftCards` | **求签三选一**（需要动手） |
| 6 | `#slotBar` | 签缘剩余与三格锦囊 |
| 7 | `#passiveSummary` | 本副签效 |
| 8 | `#nextBox` | 牌墙预览 |
| 9 | `#btnSwap` | **换牌**（需要动手） |
| 10 | `#btnHu` | 胡牌只在能胡时出现 |
| 完成 | 结算屏 | 得分 = 牌值 × 番势 → 进入主界面 |

从按下胡牌到收尾约 7.5 秒（结算动画照常播，那是这游戏的爽点，不该跳过）。

### 2. 固定牌谱，不靠 seed

`Run.loadScriptedHand({ hand, wall, flavorId, swaps })` 用牌谱记法直接替换当前这一副。

教学的每一句话都在描述具体那几张牌（「已经替你选好三张一萬」「下一张正好是九萬」），
靠 seed 去撞出一副合适的牌太脆——改一次平衡数值教学就对不上了。

牌谱：手牌 `111m 234m 567m 78m 99p E`，牌墙 `9m 5p 3s 4s 6s`。
起手正好差 1 张、正好有一个可亮的刻子、正好有一张废牌可换，换完立刻能胡。
`tests/src-tutorial.test.mjs` 把这些前提全部断言下来了——牌谱一改，测试先红。

### 3. 玩家不可能走错

四块遮罩围出一个「洞」，只有被高亮的那一处可点，其余点击一律挡掉。
需要选牌的步骤（亮组、换牌）直接替玩家把牌选好，他只需要按那一个按钮。
所以脚本永远不会被玩家带偏，也就不需要写任何「玩家乱点之后怎么恢复」的补救逻辑。

跳过按钮在说明卡里，永远在最上层。

结算屏那一步例外：不挖洞也不压暗（结算屏本身就是要读的内容），
但仍铺一层**透明的挡板**，并把结算屏自己的「本关结算」按钮藏起来——
教学里只留「进入主界面」一个出口，不能让玩家顺着这一局继续打下去。

### 4. 教学局绝不落档

`attach(run, { persist: false })` → `watchSaves` 直接返回，不订阅。

不这么做的话，打完教学回到标题页会冒出一个「继续上局」，点进去接回教学那副牌。
教学开始前挂着的那个 Run 会被记下来，结束时再挂回去当标题页背景。

### 5. 什么时候出现

- 普通加载永远先到标题页，不自动弹教学。
- 点“开始新局”时，只有同时满足`没有可恢复存档`和`tianhu.tutorial.v1 未完成`才进入教学。
- 教学完成或跳过后，直接开始玩家刚才请求的新局，不再退回标题页让玩家点第二次。
- 有旧存档说明玩家已经玩过；即使本机没有教学标记，点“开始新局”也直接开局。
- 标题页新增「教学」按钮，随时可以重看。
- `?tutorial=1` 强制播，`?tutorial=0` 关掉——自动化测试用后者。

## 影响与验收

- `node --test tests/*.test.mjs` 149 项全绿（新增 3 项教学牌谱断言）。
- `node tests/src-viewport-smoke.mjs` 58 项全绿，新增六视口教学检查：
  说明卡必须完整在屏内、跳过按钮 ≥44×44、固定牌谱发 14 张、亮组那一步替玩家选好 3 张。
- 2026-08-01 viewport 流程已自动验证：首次加载先见标题、首次点开始进入教学、跳过后直接开新局、
  旧玩家点开始直接开局，以及标题背景 / 教学临时 Run 不因普通保存或生命周期暂停写入正式存档。
- 手动重看与完整十步教学仍需一次真人复核；自动化只证明流程和布局可用，不证明教学文案节奏合适。

## 一个被测试当场抓到的问题

教学的「跳过教学」原来用 `.btn.sm`，实测只有 60×34，低于项目其它地方守的 44px 触控下限。
是新加的六视口检查报出来的——改按钮，不是改测试。

## 没做的事

- 教学不介绍商店、圈主、跳局、福将和牌骨；那些等玩家真的打到再说，
  第一次上手塞十步已经是上限。
- 教学没有做「拖拽出牌」的强制练习，只在换牌那一步的文案里提了一句。
  真人试玩时要看有多少人自己发现拖拽。
