# 0023 · 质感第一步：全屏背景 shader 与弹簧动效

状态：`Accepted`（实现完成）
日期：2026-07-28

## 背景

用户玩过之后的判断是「画面和效果都没有质感，跟小丑牌差得远」，并且问要不要上游戏引擎。

**结论是不需要引擎。** 小丑牌自己用的是 LÖVE（Love2D）——一个很薄的 Lua + OpenGL 封装，
没有场景图、没有编辑器、没有物理系统，能力上并不比我们现在的「DOM + canvas」强。
它的质感来自三样东西，没有一样是引擎给的：手绘像素美术、GLSL shader、弹簧动效。
换 Unity / Godot 不会有任何一行自动变好看，还会把包体从几百 KB 干到几 MB，
而 Playables 是有体积预算的——我们「零外部请求、全自绘」的架构正是为它选的。

诊断出四条差距，按贡献质感的权重排：

1. **我们的「像素画」其实是被二值化的系统字体。** `glyphSprite()` 把 PingFang 的字做 alpha
   阈值硬化，它永远只会看起来像一个被压扁的字体。灵签更严重：卡面本质是「色块 + 方框里一个字」，
   而小丑牌每张牌都有独立插画。这是前两轮做卡面放大、加斜纹、加高光都没能真正解决问题的根因。
2. **完全没有 shader 层。** 画面里没有任何东西在呼吸。
3. **动效是写死时长的 CSS keyframes，不是弹簧。**
4. **音效是裸振荡器。**

用户选择先做 2 和 3（纯技术、我能独立完成），美术方向暂时沿用现有的深玉绿 + 朱金配色。
本文只记 2 和 3。

## 决定

### 1. 全屏背景 shader（`src/render/backdrop.mjs`）

一个 fixed 的 `<canvas id="backdrop">` 铺在最底层，跑一段 WebGL1 fragment shader：
hash 值噪声 → 4 阶 fbm → **域扭曲**（让噪声自己推自己，出漩涡而不是平移）→ 三色映射 →
中央聚光 + 四周压暗 → 一层极轻的颗粒防色带。

- **底色跟着关卡走**：东 / 南 / 西圈各一套，打圈主时整个画面转红，标题页另有一套。
  换色是插值过去的，不硬切（`syncBackdropTone()`）。
- **半分辨率渲染**（`RESOLUTION_SCALE = 0.5`）。底是低频大色块，半分辨率完全够用，省一半像素填充。
- **三条兜底**：拿不到 WebGL 就返回 `null`，body 的 CSS 渐变照常兜底；
  `prefers-reduced-motion` 或设置里关掉动画时只画一帧静态图；标签页不可见时停掉 rAF。

为了让它真的看得见，牌桌 `#table` 改成半透（`rgba(20,52,42,.62)`），标题页也从一整块
死渐变改成半透。标题页半透之后底下的牌桌 UI 会透出来，所以加了 `body.atTitle`：
`#app` 压到 7% 不透明度并加 3px 模糊——不模糊的话「0 / 400」这种数字还认得出来，
读起来像脏东西而不是背景。

### 2. 弹簧动效（`src/ui/spring.mjs`）

CSS keyframes 是一条写死的曲线，起点终点都固定，播到一半被打断就会跳。
换成弹簧：目标随时可以改，速度是连续的，超调回弹是算出来的。

每个元素有 5 个通道（`lift` px / `scale` 倍 / `rx` `ry` `rot` 度），共用一个 rAF 循环。
只有真的在动的元素在循环里，静下来自动退出；元素从 DOM 摘掉自动注销，
`renderAll` 反复重建也不会泄漏。

三种用法：

- `springTo(el, targets)` — 设目标。手牌的 hover 抬起、选中抬高并轻微歪一下走这个。
- `impulse(el, {lift, scale, rot})` — **直接给速度，不改目标**。结算时「被点名的卡弹一下」走这个，
  比设临时目标再设回来自然，也不会和别的目标打架。
  ⚠️ 给的是速度不是位移：按现在的刚度 / 阻尼，峰值位移 ≈ 速度 × 0.035，
  所以「跳 14px」要给 400 左右。第一版按位移填了 52，肉眼完全看不出来。
- `attachCardMotion(el)` — 卡片手感三件套：**常驻微浮**（每张卡随机相位，画面才不像贴图）、
  **指针跟随的 3D 透视倾斜**、hover 抬起 + 轻微放大。求签卡、商店卡、顶部的灵签都挂上了。

配套改动：

- `.sprung` 类禁掉 CSS transition，`#handZone / #draftCards / #shopGrid / #slotBar` 加 `perspective`。
- 删掉和弹簧打架的 CSS：`.tile:hover/.sel` 的 `translateY`、`.charmPick:hover`、`.shopCard:hover`、
  以及 `popScore` / `slotPop` 两条关键帧。`glowBone` / `glowSeal` 只改 filter，保留。
- 求签卡的 `attachCardMotion` 延后 400ms：`dealIn` 是 transform 关键帧，
  CSS 动画在层叠里压过内联样式，得等它播完再交接。
- 设置里「动画：关」会同时停掉弹簧和 shader（`setSpringMotion` / `backdrop.setEnabled`）。

## 影响与验收

- 规则、数值、存档 schema 未动。`node --test tests/*.test.mjs` 134 项全绿。
- `node tests/src-viewport-smoke.mjs` 39 项全绿：无裁切、无遮挡、无页面滚动，最小可点 ≥44×48px。
- 新增两个模块共约 380 行，零依赖、零外部请求，仍然满足 Playables 的自包含要求。

## 没做的事（也是现在真正的天花板）

- **美术资产没动**，这是四条差距里最大的一条。牌面仍然是系统字体二值化，
  灵签仍然是「方框 + 单字」。CSS 和 shader 到此为止能做的都做了，
  再往上必须换成手工点的精灵和每张卡的独立插画。
- 音效仍然是裸振荡器（差距 4）。
- 彩签的 holo / 箔面材质没做。真要做可以用 CSS 混合模式近似，不一定上 WebGL。
