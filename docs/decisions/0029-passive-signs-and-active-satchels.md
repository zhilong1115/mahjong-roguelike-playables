# 0029 · 被动签效与三格主动锦囊

状态：`Proposed`（用户确认方向；最小可玩切片已实现，等待真人试玩）

日期：2026-07-31

## 玩家问题与目标乐趣

当前六个开运位同时表示亮组次数、空位金币和已经取得的灵签。大多数灵签在选中时就已经生效，
却仍然以六张大卡长期占据牌桌顶部；玩家看见很多牌，却没有几张能在“这副好像胡不了”时主动救场。

下一版要把两种乐趣分开：

```text
被动签效：选中即生效，负责本副加分、特殊属性或留下签兆
主动锦囊：选中后存起来，玩家在需要时点击使用，负责救牌或追更大的胡
```

成功信号不是单纯减少卡片数量，而是玩家一眼知道“上面这三张是我现在可以按的救命牌”。

## 三种不同资源

### 1. 求签机会：仍先保留 6 次

- 每亮一个合法组合，永久花掉本副 1 次求签机会并进行一次三选一。
- 未使用的求签机会仍在胡牌后兑换 `牌值 + 金币`，继续承担“短期强化 vs 长期经济”的取舍。
- UI 不再把六次机会画成六张大卡，只显示紧凑计数，例如 `签缘 4/6 · 每剩 1 次 +2 金`。
- 使用锦囊不会返还求签机会；否则玩家可以反复用掉锦囊、腾位、继续求签形成循环。

### 2. 被动签效：立即结算，不占顶部锦囊位

以下灵签在取得时直接写入本副状态：

- 助势：顺子、刻杠、对子、字牌、剩余换牌等加分或加番。
- 即时奇缘：立刻返金、立刻增加本副属性。
- 延时奇缘：留下现有单格 `待缘位` 签兆，等下一次求签时消费。

顶部不再逐张展示这些签。左侧保留一个可点摘要，例如 `本副签效 3`；点开后查看完整清单、
叠加值和结算顺序。结算播到某个签效时，可以短暂浮出对应签牌并让摘要跳动，仍然保持因果可读。

### 3. 主动锦囊：顶部最多携带 3 张

- 主动牌取得后进入 `锦囊位`，最多三格，默认只持续本副。
- 玩家可在组牌阶段、胡牌结算前随时点击使用；每张一次，用后消失并腾出携带位。
- 腾出的只是携带位，不恢复已经花掉的求签机会。
- 三格已满时仍可选择新的锦囊，但必须在同一层明确选择替换哪一张；不能静默丢弃。
- 本副结束时未使用的锦囊消失，不兑换金币，形成“用掉还是浪费”的轻压力。
- 需要目标的锦囊先预览结果，确认后才消费；取消返回牌桌，不能误触直接烧掉。

## 求签三选一

第一次切片不强制每次都出现主动锦囊。候选仍由当前局面与 seed 决定，但职责收敛为：

1. 一张适配当前组合或牌型的被动助势。
2. 一张当前确实可用的主动锦囊；没有合法目标或三格全满且不适合替换时，回退为另一张被动签。
3. 一张高波动被动、签兆或稀有主动锦囊。

卡面必须明确标 `立即生效`、`收入锦囊` 或 `留下签兆`，不能让玩家选完才知道去向。
现有银 / 金 / 彩仍表示稀有度，不代表主动或被动。

## 首批主动锦囊

第一轮只测试用户最直接提出的三种救牌行为：

| 名称 | 建议签阶 | 效果 | 关键边界 |
|---|---|---|---|
| 续巡锦囊 | 银 | 本副额外获得 2 次换牌 | 额外换牌不计入“剩余换牌换金币”，避免凭空套利 |
| 洗壁锦囊 | 银 | 按记录 seed 重洗剩余牌墙，并刷新可见预览 | 牌墙实体集合不变；牌墙不足 4 张时不进入候选 |
| 点石锦囊 | 彩 | 选择一张未亮牌，再指定它本副视为哪一种合法麻将牌 | 不能造第五张同牌；允许直接成胡；本副最多使用 1 张改命类锦囊 |

`点石锦囊`的强度目标就是“关键时刻救命”，因此允许玩家指定目标，不只自动给一个答案；
但必须用彩签稀有度、三格携带上限和每副一次改命限制控制频率。后续可以再加入：

- 借张锦囊：从牌墙前 3 张选一张与手牌交换。
- 移花锦囊：一张数字牌保持点数、改成另一花色。
- 归一锦囊：整组改花色，用于从小胡升级清一色或一条龙。

这些沿用 `0014` 的合法目标、本体牌种 / 有效牌种和预览规则，不重复建立第二套改牌系统。

## 使用时序与交互

```text
点击顶部锦囊
→ 查看效果与“使用 / 返回”
→ 若需目标，只高亮合法未亮牌
→ 选择目标牌种或牌墙候选，预览“还差 2→1 / 1→0 / 新增清一色”
→ 确认后消费锦囊并即时存档
```

- 不依赖拖拽、悬停或长按；触控和鼠标都走点击确认。
- 即时锦囊从点击到生效目标不超过 2 秒；带目标锦囊完整流程目标不超过 8 秒。
- 锦囊使用不消耗普通换牌次数，也不额外占一次求签机会；取得它时已经支付过一个开运机会成本。
- 同一副可以组合使用辅助类锦囊，但最多使用一张改变牌身份的改命类锦囊。
- 求签层、锦囊目标层、结算层和商店层互斥，避免多个根级弹层叠在一起。

## 与现有规则的关系

- 本提案保留 `0009` 的六次求签经济，但修订“六个开运位都展示已选灵签”的表现与职责。
- 若切片通过，`0024` / `0025` 的顶部六张大开运牌架将由“三格锦囊架 + 紧凑签缘计数”取代；水墨材质方向不变。
- 现有 `待缘位`继续只放跨副一次性签兆，不占锦囊位。
- 主动和被动仍属于 `family: charm`，Library 增加稳定字段区分 `resolve / reserve / omen`，不增加第六类商品。
- 结算只读取已经生效的被动签效；未用锦囊不能在胡牌时自动触发。
- 实现时建议把存档升为 schema v5，保存三格锦囊、已使用的改命次数、目标选择中间态和奖励型 / 额外换牌的分别计数。

## 为什么不把六格直接改成三次求签

三张锦囊位是库存上限，不应该同时成为求签次数。如果直接只允许三次亮组：

- 七对、连续亮组和多次三选一构筑会被一起削掉。
- 空位金币从六档变三档，整局经济和商店价格都要立即重标。
- 使用锦囊后是否恢复格子会变成难以解释的新规则，并可能产生循环。

因此第一版只分离职责，不同时改求签次数和经济。真人试玩若仍认为六次选择太多，再单独测试 4 次求签，
不能把“卡太多”和“选择太多”两个问题一次混在一起。

## 最小验证

准备三套固定牌谱：

1. 已经可胡：被动助势应比救牌锦囊更有吸引力。
2. 还差 1–2 张且换牌不足：玩家应主动储存并使用续巡、洗壁或点石。
3. 已经小胡但接近清一色 / 一条龙：玩家要在立即加分和保留改命锦囊之间犹豫。

记录每副求签次数、取得 / 使用 / 浪费的锦囊数、第一次使用时机、从不能胡到能胡的转化、
单次操作用时，以及是否有人误以为使用锦囊会返还求签机会。

## 2026-07-31 实现切片

- 顶部已改为 `签缘 0–6` 计数和三格锦囊；被动签移入左侧可点的`本副签效`摘要。
- Library 新增续巡、洗壁、点石三张主动牌，现行灵签 / 锦囊共 22 张，五系合计 41 张。
- 续巡的 2 次额外换牌和原有奖励型换牌分账；只剩额外换牌时不会凭空兑换金币。
- 洗壁使用当前 run seed 和本副洗牌次数确定性重排剩余牌墙，实体集合不变。
- 点石使用`选原牌 → 选合法目标牌种 → 预览 → 确认`；不造第五张同牌，本副限一次，允许直接成胡。
- 三格满时进入明确替换层；取消不改签局、不丢旧锦囊。本副结束后未用锦囊消失。
- 存档升到 schema v5，并保存锦囊、额外换牌分账、洗壁次数、点石限制与目标选择中间态。
- 自动测试已覆盖规则、v4 → v5 迁移和 required 六视口完整点石流程；这只证明切片可操作，不代表乐趣与数值已成立。

## 成功信号与回退

- 玩家无需教程就能指出顶部三张都是“现在可以用”的牌。
- 至少一套救牌牌谱中，玩家会主动储存锦囊，并在换牌即将耗尽时使用。
- 已经可胡的牌谱中，被动助势仍有合理选择，不是永远拿主动牌。
- 没有死锦囊、第五张同牌、非法亮组、重载换目标或额外换牌金币套利。
- 三格满时的替换决定不超过 5 秒；带目标使用不超过 8 秒。
- 如果玩家仍分不清求签次数与锦囊位，先把签缘计数放在锦囊架旁并强化“取得已花 1 缘”；不立刻砍求签次数。
- 如果玩家长期把锦囊留到消失，增加结算前一次“还有锦囊未用”的轻提示；不自动替玩家使用。
- 只有完成规则测试、schema 迁移、required 视口和真人试玩后，才能把本提案提升为 `Accepted`。
