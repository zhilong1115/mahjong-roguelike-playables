## 现在能玩到什么

正式版骨架与 `0017` 六关短局已经可以完整走通：`src/index.html`。圈关规则仍是
`Proposed`，实现完成不等于已经接受。

```bash
node tools/dev-server.mjs
```

打开 `http://127.0.0.1:4173/src/`，加 `?seed=数字` 复盘同一局，加 `&intro=0` 跳过玩法说明。

- 标准局为东 / 南两圈，每圈依次经过闲局、庄局、圈主三关，每关只打一副；通关后可选西圈加赛。
- 闲局和庄局可跳过换一张手气；圈主必须打，并带一条开打前可见的单变量规则。
- 每个打赢的非最终关后进入百宝阁；标准全打六副、五家商店，其中第 1 / 3 / 5 家是三条路线各一位的阶段请将台，第 2 / 4 家提供长期改造。
- 每副 14 张结构牌、5 次**换牌机会**（一次可换多张，没用完的每次胡牌换 2 金）、默认 6 个开运位；亮组通常三签选一，广缘兆应验时四签选一，合法时可胡。
- 牌墙预览张数跟着起手打碎张数走：东圈看 2 张，南 / 西圈看 3 张；圈主「独眼张」会遮住预览。
- 灵签同时显示银 / 金 / 彩签阶与助势 / 改命 / 奇缘职责；引路、聚雷、红线是金签，选择后由玩家指定原牌和合法目标，鸿运和广缘会留下一个跨副保留、下次求签消费的待缘兆。
- 单副达到本关目标后，待结算金币与过关金入账；终局福将 / 彩签可以把当前番势 ×2 或 ×3，最终得分仍显示为 `牌值 × 番势`。现有目标暂未重标。
- 开始界面可继续存档或选择四种牌组；当前存档 schema 为 v4，并兼容读取 v1–v3。
- 标题页和局内都可打开「百牌谱」；现行 38 张五系卡由同一 Library 供抽签、商店、计分和图鉴使用。
- 标题页使用本地水墨山月背景与“墨圈 + 行楷 + 朱砂印”Logo；求签 / 商店是占满屏幕的一次性弹窗，卡面最高 430px。
- 顶部开运位只放灵签；番谱 / 牌骨 / 牌印在常驻栏是可点摘要，点开分别看番率表和每个牌种改了什么。
- 装了牌骨的牌在牌面上就是另一种料子（玉 / 竹），装了牌印的牌右上角有一枚朱砂印。
- 结算按步分档播放（一副约 8.5 秒，可点击快进），算到哪张卡哪张卡就跳一下并亮一圈金光。
- 出牌两种操作都行：点选后按上方按钮，或直接拖起手牌——落在按钮上执行那个动作，落在牌桌上执行默认动作，落在别处作废。
- 胡牌按钮平时不显示，只有真的能胡时才出现（出现本身就是提示）。
- 横屏恢复为左侧关卡 / 牌势 / 资源 / 构筑，右侧开运位 / 牌桌 / 操作 / 手牌；不再使用顶部构筑带。
- 844×390 的左栏四组完整入屏；667×375 只把左栏缩到 116px，并以轻微叠边保持 14 张同排。
- 画面底下是一层缓慢翻涌的淡墨 WebGL shader，色调跟着圈和圈主微调；卡会常驻微浮，鼠标划过会朝指针做 3D 倾斜。
- 19 张灵签和 11 位福将都有独立原创卡图；顶部开运牌架在桌面 / 方屏实测高 132px、矮横屏 68px，中央每组只放一张大牌并标 `对 / 顺 / 碰 / 杠`。

## 已知问题

- `0027` 的全宽底栏已被真机否决；`0028` 用 116px 左栏和轻微叠边覆盖 667×375。宽度低于 667px 的极窄横屏尚未设为单排保证，仍按平台 resize 时的完整可操作优先。

- `0017` 仍为 `Proposed`；六关短局和西圈加赛不是已冻结规格。
- 六关自动路线通关率为 82.5%–92.5%，目标可能偏松；尚无真人 5–8 分钟完整局计时。
- 三阶段路线将价格为 8 / 14 / 22 金；标准局能否稳定买到终局将、跳过请将是否形成有意义选择仍未真人验证。
- 开局三选一和商店签筒 / 牌包尚未实现，所以当前只是提高了商店频率，还没有完成用户期待的抽卡型商店。
- 固定职责货架是实验设定，不是正式规则；牌帖也只是当前无持久实体牌库时的过渡方案。
- 自动试玩 AI 在圈关流程下流局率约 1%（修好七对打碎上限与预览张数之后）；真人流局率未知。
- 当前引路 / 聚雷 / 红线是自动改一张的最小切片；`0014` 的借张、移花、归一和听风等需要玩家选目标的交互式改命仍未实现。
- `0020` 的路线候选目前固定，重复游玩可能过于稳定；现有六关目标也尚未按番势乘算重新标定。
- 虹福签只是让彩签能真实生成、展示和结算的实验占位卡；72 / 25 / 3、鸿运 15% 升彩与虹福数值都没有真人数据。
- 当前 11 张签能保证普通 / 广缘签局有足够合法内容；以后删签或收窄候选池时，必须先加“亮组前可生成完整签局”的 invariant 或事务回滚，不能让亮组完成后才发现签池不足。
- `0016` 的叠杠与十四归一只是设计记录；当前四张同牌上限、胡牌判定和 schema v4 均未为它改动。
- 番谱 / 牌骨 / 牌印已改成线装书、材质牌坯和朱砂印的代码绘制物件；同系多张仍共享物件轮廓，内容定型后再补逐张纹样（`0024`）。
- 牌骨材质只做了温玉 / 青竹两种。以后加牌骨必须同时在 `pixel.mjs` 的 `TILE_MATERIALS` 里加料子，
  否则会静默退回象牙面，牌面上看不出区别（`0021`）。
- 2026-07-26 已修复 360×800 求签裁切，并把 smoke 扩展为 overflow 祖先可见交集、中心点遮挡、三 / 四签六视口与 `1–4 / Esc`。牌桌部分旧控件在矮横屏仍约 44–45px；新增待缘位和签卡达到 48px 目标。
