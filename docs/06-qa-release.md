# QA and Release

## 测试类型

### 规则测试

- 每种番种的正常、边界和冲突案例
- 强化牌与福神牌触发顺序
- Boss 限制
- 商店经济
- 固定 seed 重现

### 玩法测试

- 新玩家是否在 45 秒内完成第一次有效出牌
- 是否理解筹码×倍率
- 每次决策耗时
- 第一张构筑奖励出现时间
- 一局完成时间和重开意愿
- 无解局、无聊选择和强制套路

### UI 测试

- `config/viewports.json` 全矩阵
- 触控、鼠标和键盘
- 安全区、字体、对比度和减少动态效果
- resize 不重置状态
- 无页面级意外滚动或裁切

### 平台测试

- 本地 Web baseline
- YouTube Test Suite、桌面 Web、移动 Web、Android、iOS
- TikTok CLI 预览与真机
- 弱网、后台、恢复、静音和存档失败

## 发布候选定义

- 所有 `Frozen` 决定已经实现。
- 没有 P0/P1 缺陷。
- 完整游戏至少连续运行 20 局无崩溃。
- required 视口全部通过。
- 云存档和旧存档迁移通过。
- 平台 SDK 自动测试与官方测试通过。
- 构建包、文件名、大小和网络请求合规。
- 名称、素材、字体、音频和第三方权利清单完成。

## 缺陷级别

- P0：崩溃、存档损坏、无法开始或完成游戏。
- P1：关键操作不可用、平台认证必然失败、明显数值漏洞。
- P2：局部功能、布局或体验问题。
- P3：轻微视觉、文案和低风险改进。
