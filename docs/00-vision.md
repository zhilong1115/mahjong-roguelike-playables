# Game Vision v0.1

状态：`Working Draft`

当前工作名：`天胡 / TIANHU`（Proposed）

## 一句话定位

一款适合排队、等人和通勤时即点即玩的麻将构筑肉鸽；玩家几秒理解选牌，通过短局构筑福神组合，快速打出不断膨胀的爆分。

## 目标平台

第一梯队：

- YouTube Playables
- TikTok Mini Games HTML runtime
- 独立移动网页

第二梯队：

- Facebook / Meta Instant Games（在核心版本稳定后重新核实接入资格和政策）
- 其他 HTML5 游戏门户

## 目标玩家

- 13 岁以上的休闲卡牌、麻将和肉鸽玩家
- 不要求理解传统麻将完整规则
- 典型场景是排队、等人、通勤和视频间隙

## 核心体验支柱

1. **即时**：快速加载、无需注册、立即操作。
2. **横屏牌桌**：以横屏清晰展示最多 14 张麻将牌，点击为主；竖屏仍能完整游玩。
3. **爆分**：筹码、倍率和福神牌触发形成层层升级的反馈。
4. **再来一局**：短决策、短检查点、快速失败和快速重开。
5. **简单表面、深度组合**：系统自动识别番种，深度来自构筑和牌库改造。

## 产品边界

第一版不做：

- 实时多人、聊天和公会
- 重剧情或大地图
- 强制账号系统
- 依赖服务器才能运行的核心玩法
- 大量永久数值加成
- 依赖右键、悬停或复杂拖拽的关键操作

## 暂定时间目标

- 首次可操作：≤ 3 秒
- 上手教学：≤ 45 秒
- 单次盲注：20–45 秒
- 重要检查点：≤ 90 秒
- 完整短局：8–12 分钟
- 失败到重开：≤ 2 秒

这些目标处于 `Proposed` 状态，需要试玩验证。

## 当前待定问题

1. “合法即可胡、亮组花开运位、空位换长期金币”的循环是否会产生真正取舍？V3 切片已把它做成可试玩，等真人判断。
2. 一局三轮太短，长期金币路线在自动模拟里始终不如全亮冲分；正式局要多少轮，或者金币是否需要短期用途？
3. 六次三签选一会不会拖慢短局？
4. 普通胡、七对和特殊番种的基础分与倍率如何组合，既清楚又能爆分？
5. 完整一局究竟是 5 分钟、8–12 分钟，还是更长但支持续玩？
6. 保留多少传统麻将规则，多少规则为了小游戏节奏进行简化？
7. 是否有局外解锁；如果有，解锁内容还是永久数值？
8. 正式名称、世界观和原创视觉身份是什么？

## 已确认的产品决定

- 横屏优先，按最多清晰展示 14 张牌设计。
- 每局组牌阶段从 14 张结构手牌开始，不采用必须先从 13 张摸到 14 张的传统开局流程。
- 如果完整 14 张牌构成胡牌，触发独立于普通小牌型的额外奖励。
- 竖屏必须保持完整可玩，但可以使用不同的信息层级和紧凑布局。
- 不锁定设备方向，resize 时保持游戏状态。
