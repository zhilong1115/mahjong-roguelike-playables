# 2026-07-31 · 三格主动锦囊实现检查

关联决定：`0029-passive-signs-and-active-satchels.md`

状态：`Automated Implementation / Visual Review`（等待手机真人试玩）

## 问题与假设

六张已经生效的被动签长期占据顶部，却不能在换牌将尽时主动救场。切片假设是：把六次求签机会显示为`签缘`，
把被动签收进摘要，顶部只留下三格可点击锦囊，会让玩家更清楚自己手里有哪些“现在能按的救命牌”。

## 实现范围

- 续巡：增加 2 次额外换牌，并与可兑换金币的原有换牌分账。
- 洗壁：以 run seed 确定性重洗剩余牌墙，不增删牌实体。
- 点石：选择一张未亮牌、指定任意不造第五张的合法牌种、预览后确认；本副改命限一次。
- 三格已满时明确替换；取消不丢旧锦囊。被动签进入可点摘要，待缘位保持独立。
- schema v5 保存锦囊、额外换牌、洗壁次数、改命限制和主动选择中间态；v4 显式迁移。
