# 圈关数值重标自动模拟

- 日期：2026-07-26
- 类型：固定规则自动模拟，不是真人试玩
- 对应决定：`docs/decisions/0013-ante-structure-and-meta-shell.md`
- 状态：已记录观察；`0013` 继续保持 `Proposed`

## 要验证的问题

旧九关目标与牌型分差过大，七对打碎三张时容易因信息不足流局。需要确认抬高普通胡地板、重排牌谱、限制七对打碎张数并增加南 / 西圈预览后，四种基本路线是否都能完成整局，同时保留分数与金币取舍。

## 测试设置

- 三圈九关，每关两副。
- 四种策略各运行 40 局：门清全打、每副亮两组全打、尽量全亮全打、门清并跳过闲局。
- 自动玩家按可见牌墙批量换牌；结果只能用于发现结构和数值问题，不能代替真人对规则可读性、操作时间和乐趣的判断。

## 本轮改动

- 九关目标改为 `750 / 1100 / 1300`、`1500 / 1900 / 2400`、`2600 / 3300 / 4600`。
- 普通胡增加 `+1` 番势，抬高最低得分。
- 七对最多打碎两张。
- 牌墙预览随实际打碎张数变化：东圈通常两张，南 / 西圈通常三张；独眼张仍会遮挡。
- 商品与刷新价格约上调 60%。

## 观察结果

| 策略 | 通关 | 流局率 | 结束金币 |
|---|---:|---:|---:|
| 门清全打 | 23/40 | 1% | 225 |
| 亮 2 组全打 | 28/40 | 1% | 153 |
| 全亮全打 | 36/40 | 1% | 58 |
| 门清 + 跳闲局 | 16/40 | 0% | 110 |

- 全亮路线通关率最高，但结束金币最低，短期得分与长期资源的差异已经可见。
- 跳闲局路线通关率低于门清全打，跳局具有实际代价。
- 死亡主要集中在西圈。
- 门清路线仍能剩约 200 金，说明现有八家商店、四将位和番谱等级上限无法消化金币。

## 结论边界

本轮只支持“数值已进入可真人测试区间”，不证明九关目标或经济已经平衡。下一步应先真人试玩整局时长与路线理解，并设计新的金币出口；不建议用削弱空位或省换牌奖励来掩盖消费不足。
