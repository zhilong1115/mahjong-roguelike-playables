# 2026-08-01 · 首次教学入口门控检查

关联决定：`0030-tutorial-hand.md`；后续章节方向由 `0033-four-circle-chapter-campaign.md` 修订

状态：`Automated Implementation / Awaiting Human Playtest`

## 问题与成功信号

问题是教学在加载完成时直接接管画面，玩家看不到 Logo、菜单和模式入口，整体更像规则 Demo 而不是一款完整小游戏。

本轮成功信号：加载永远先显示标题；真正首次玩家点开始后才教学；完成或跳过后直接开新局；旧玩家不被教学截断；标题背景与教学局永不污染正式存档。

## 实现范围

- 保留固定牌谱十步教学内容与标题页手动“教学”入口。
- 首次判断改为`无可恢复存档 + 无教学完成标记`，判断时点从页面加载移到“开始新局”。
- 教学完成 / 跳过后按入口返回：首次入口直接开新局，手动入口回标题。
- 标题背景 Run 与教学 Run 显式标成不可持久化；页面切后台或刷新时也不能被生命周期保存。
- 关卡地图、1–3 星、章节 Boss 与自由模式只记录为 `Idea`，没有伪装成已验证功能。
