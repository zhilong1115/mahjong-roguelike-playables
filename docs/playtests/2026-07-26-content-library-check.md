# 五系 Library 与百牌谱实现检查

日期：2026-07-26

类型：实现 / 自动 QA，不是真人玩法结论

## 假设

1. 现行 24 张五系功能卡可以收拢到一个数据源，不改变抽签、商店、计分和存档行为。
2. 「百牌谱」能在 required 六视口查看五系卡，不出现页面级滚动、遮挡或不可达页签。

## 实现范围

- `src/content/library.mjs` 成为五系唯一卡牌清单，原有分类模块改为筛选 / 兼容导出。
- 增加 id、文案、持续时间、价格、签阶、责任、抽取池和 effect kind 校验。
- 增加 `enabled` 下架语义：列表与抽取默认排除，按 id 查询仍保留。
- 标题页和局内增加「百牌谱」入口；图鉴使用五系页签和原有卡面轮廓。

## 自动结果

- `node --test tests/src-*.test.mjs`：74 / 74 通过。
- `node --test tests/*.test.mjs`：127 / 127 通过（含历史原型回归）。
- `node tests/src-viewport-smoke.mjs`：通过。新增百牌谱灵签 / 福将切换，覆盖 360×800、390×844、844×390、768×1024、960×960、1280×720。
- 六视口都没有页面级滚动、关键区域裁切或页签中心点遮挡；页签最小高度为 44px（矮横屏），其余为 48px。
- 人工查看 360×800 和 844×390 截图：五系文字、数量、卡名、效果、价格 / 持续时间可读，与现有像素牌馆视觉一致。

## 结论边界

这些结果只证明统一 Library 没有破坏现有流程，且图鉴在目标视口可操作。它不证明玩家能在一局内理解五系，也不代表候选改命签已实现。
