# 金色定向改命交互检查

- 日期：2026-07-27
- 类型：规则 / 存档 / 响应式自动检查，不是真人试玩
- 对应决定：`docs/decisions/0014-charm-momentum-and-fate.md`、`0020-archetype-generals-and-power-curve.md`
- 状态：最小切片已实现；稀有度、强度与选择时长仍为 `Proposed`

## 要验证的问题

聚雷签能够定向救胡，强度不应伪装成普通银签；玩家也应该拥有最后决定权，而不是系统自动改掉一张牌。

## 实现范围

- 引路签、聚雷签、红线签统一从银签升为金签。
- 选择改命签后不立即取得：先重画当前 14 张未亮手牌，只让存在有效改法的原牌可点。
- 选定原牌后，只显示会真实降低“还差几张”的目标牌；按流派潜力排序，但不替玩家选择。
- 点击目标牌即确认，保留实体牌 id，不消耗换牌次数，不允许造出第五张同牌。
- Esc / 按钮可以从目标返回原牌，再返回原三签；确认前不取得灵签、不改变手牌。
- 选择中途完整保存在现有 schema v4 的签局快照里，恢复后仍停在同一张原牌。

## 自动观察

- 固定一向听牌谱中，确认聚雷 / 红线的合法目标后距离从 1 降到 0；确认前手牌与灵签列表不变。
- 同一签局可以取消回三签，也可以在恢复存档后重选原牌并继续确认。
- 已经成胡时，改命签 id 会从新签局候选中排除，避免出现没有目标的金签。
- UI 使用明确的牌面按钮和“可改 / 无改善 / 立即可胡”文字，不只依赖颜色。

## 真人试玩仍需回答

1. 金签稀有度是否与“定向救胡一次”的主观强度匹配，还是应该升为彩签。
2. 玩家能否在 8 秒内完成两步选择，并理解灰牌不是 bug、而是没有有效改善。
3. 只允许降低成胡距离是否太保守；未来是否允许距离不变但新增清一色、一条龙等“升胡”目标。
