日期：2026-07-25

试玩入口：`prototype/v2-run-shop-demo/`

状态：`Internal Verification / 用户手感待测`

## 本轮要验证什么

1. “合法即可胡、亮牌只为开运和加分”能否形成完整可玩的流程。
2. 门清金币是否能在三副后立即兑现为整局福将。
3. 七对、普通胡和特殊番种能否共用同一套 1–4 张操作。
4. 旧 Demo 的像素街机牌馆质感能否在不复制名称、素材和精确布局的前提下延续。
5. 横屏主体验、竖屏降级布局和商店是否都可操作。

## 尚不能下的结论

这次内部验收只能证明流程完整、规则一致和界面可操作，不能证明它已经好玩。以下仍需用户与陌生玩家实际试玩：

- 是否能在 45 秒内复述“门清拿钱、亮牌开运”。
- 胡牌就绪后，立即胡与继续亮牌是否真有犹豫，而不是存在固定最优解。
- 三副牌加商店能否稳定控制在 90 秒左右。
- 灵签触发是否足够有爽感，福将是否值得期待。
- 竖屏虽然完整可玩，是否需要进一步提高信息字号和仪式感。

因此 `0007` 与 `0008` 继续保持 `Proposed`，不在本轮提升为 `Accepted`。

## 用户首轮方向反馈

用户试玩后认为“这个玩法思路大概对了”，支持继续保留：合法即可胡、主动亮牌换取本副收益、不亮牌积累长期金币、三副后进入商店。

用户同时要求下一轮调整：

- 每次亮牌后的奖励改为三张灵签选择一张，而不是固定取得下一签。
- 灵签可能强弱不同，效果可包含本副加分或立刻增加 1–2 枚金币。
- 亮牌应明确服务短期得分；保留空位和金币服务长期构筑。
- 上方组合 / 开运区统一显示最多 6 个位置。
- 胡牌时每少使用一个位置，就按位置数量获得金币；金币总量应高于 V2。

这条反馈支持 V2 的价值方向，但不支持保留 V2 的“最多亮两组、固定灵签、3 / 1 / 0 金币”参数。下一轮提案已记录为 `docs/decisions/0009-six-fortune-slots-and-three-choice-draft.md`，仍保持 `Proposed`，本次没有修改代码。
