# 六关短局最小切片检查

- 日期：2026-07-26
- 类型：规则 / 存档 / 自动路线检查，不是真人试玩
- 对应决定：`docs/decisions/0017-short-run-shop-cadence.md`
- 状态：最小切片已实现；`0017` 继续保持 `Proposed`

## 假设

把标准局从最多 18 副缩到 6 副，并让每次胜利后几乎立即进入百宝阁，可以提高构筑反馈频率；保留西圈作为可选加赛，不应重新拉长默认流程。

## 实现范围

- 新局默认启用东 / 南两圈，每圈闲局、庄局、圈主，每关一副。
- 标准全打六关、五家商店；南圈圈主后显示短局通关。
- 通关页可选择进入西圈三关加赛；加赛增加两家商店。
- schema v4 增加可选 `activeAnteCount`；已经进入西圈的旧 v4 存档恢复后继续三圈。
- 开局三选一和商店签筒 / 牌包尚未实现，留给下一切片。

## 固定结构检查

自动测试强制清关后观察到：

- 标准局恰好 6 关、5 家商店。
- 西圈加赛恰好 3 关、2 家商店。
- 标准通关可进入加赛；加赛通关后不能重复进入。
- 两圈 / 三圈状态可存档往返，旧 v4 西圈档不会被截断。

## 首轮自动路线（每种 40 局）

自动玩家会购买当前买得起的货架商品；结果只用于检查目标线是否明显失效。

| 路线 | 通关 | 平均结束金币 | 平均商店数 | 平均过关数 |
|---|---:|---:|---:|---:|
| 门清全打 | 33/40 | 41.7 | 4.8 | 5.6 |
| 每副亮 2 组 | 37/40 | 33.6 | 5.0 | 5.9 |
| 尽量全亮 | 34/40 | 17.6 | 4.8 | 5.7 |
| 门清 + 跳闲局 | 34/40 | 30.7 | 2.9 | 3.7 |

## 观察与边界

- 四条路线通关率为 82.5%–92.5%，初始目标线没有让整局普遍中断，但可能偏松。
- 获胜路线基本能看到五家商店；跳闲局会把商店减少到约三家，代价清楚。
- 门清仍最有钱、全亮最穷，但金币已不再堆到旧版约 200 的量级。
- 自动玩家不能判断商店是否有趣、长期商品是否来得及成形，也没有真实操作与动画耗时。
