# V3 街机切片内部验收

日期：2026-07-25

试玩入口：`prototype/v3-arcade-demo/`（可加 `?seed=数字` 复现同一局）

状态：`Internal Verification / 真人手感待测`

## 本轮要验证什么

1. 六个开运位、每次亮牌三签选一、空位兑换金币能否形成一条可理解的曲线，而不是「全亮」或「全不亮」二选一。
2. 保底可解的发牌器能否让流局变成玩家失误，而不是运气。
3. `legacy-demo.html` 的街机牌馆质感能否在模块化结构和零外部请求的前提下延续。
4. 六个 required 视口（含 844×390 主视口和 360×800 竖屏）是否都完整可玩。

## 已实现切片

```text
三轮 × 三副，目标 900 / 1700 / 4500
→ 每副 6 个开运位、5 次换牌、牌墙预览 2 张、界面显示「还差 N 张」
→ 亮组花 1 格 → 原位三签选一（本组签 / 牌型签 / 奇签）
→ 胡牌得分 = 牌值 × 番势，空位每格 +12 牌值 +2 金
→ 三副达标金币入账 → 百宝阁三选一（3 金刷新，最多 4 位福将）→ 下一轮
```

牌型：普通胡、七对、碰碰胡、清一色、一条龙、大三元、大四喜，门清作为名牌标签。
内容量：15 张灵签、9 位福将、7 种目标牌型牌谱。

## 尚不能下的结论

自动测试只能证明流程完整、规则一致、界面可操作，不能证明好玩。仍需真人试玩：

- 45 秒内能否复述「空格 = 牌值 + 金币，花掉 = 一次三签选一」。
- 胡牌就绪后是否真的会犹豫，而不是永远全亮或永远直接胡。
- 三副 + 商店能否控制在 90 秒左右；连续六次三签选一是否拖慢节奏。
- 流局是否会被理解成自己的选择失误。
- 竖屏 7 + 7 布局的牌面尺寸是否够看。
