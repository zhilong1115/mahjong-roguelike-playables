玩法说明

门清拿钱 · 亮牌开运

  1. 选 1 张：换掉并从牌墙摸一张，消耗一次行动。
  2. 选 2–4 张：亮出对子、顺子、刻子或杠，抽一张本副灵签。
  3. 牌型合法：可以随时胡；未亮组合会在结算时自动计算基础分。
  4. 完全门清：胡牌获得 3 金币；亮一组得 1 金，亮两组不再得金。
  5. 三副之后：金币在百宝阁购买整局生效的福将。

本切片支持普通胡、七对、碰碰胡、清一色、一条龙、大三元与大四喜。
